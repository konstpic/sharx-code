Configuration

Manage your cluster via environment variables.

# .env.production
XUI_WEB_PORT=2053
XUI_WEB_LISTEN=0.0.0.0
XUI_DB_HOST=db.cluster
XUI_LOG_LEVEL=debug
XUI_ENABLE_FAIL2BAN=true
XRAY_VMESS_AEAD=forced
Variable Description Default
XUI_WEB_PORT Main panel port 2053
XUI_DB_HOST PostgreSQL host address localhost
XUI_SUB_PATH Public path for subscriptions /sub
XRAY_VMESS_AEAD_FORCED Enforce AEAD for VMess clients false
XUI_ENABLE_FAIL2BAN Brute-force protection enabled true
