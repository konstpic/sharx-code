# Playfair Display

Unmodified variable fonts from [Google Fonts](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/playfairdisplay), revision `8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`.

Normal and italic fonts include Latin and Cyrillic glyphs. Licensed under the SIL Open Font License 1.1; see OFL.txt. Bundled locally so the panel build does not depend on Google Fonts URL formats for this family.
