## Release v1.7.24

**Release Date:** September 19, 2026

Релиз **v1.7.24** относительно **v1.7.23**: белый список приложений для подписок и исправление нечитаемых баннеров в светлых темах.

**Миграция БД:** нет.

---

### Feature: белый список приложений (subAppGateAllowedApps)

Раньше можно было только блокировать конкретные приложения, и чтобы оставить, например, только Incy, приходилось перечислять все остальные. Теперь в настройках подписок рядом с чёрным списком есть поле «Разрешённые приложения (белый список)».

- Если поле не пустое, подписку получают **только** перечисленные приложения, остальные (включая нераспознанные) блокируются. Чтобы оставить только Incy, достаточно вписать `incy`.
- Пустое поле — любое приложение (как раньше).
- Чёрный список приоритетнее белого. Режим «Требовать распознанное приложение» срабатывает первым.
- Заблокированные приложения видят замечание «Заблокированное приложение» из «Замечаний подписки» (не голый 403).
- Работает для обычной и `/json/` подписки. Ключи проверяются при сохранении настроек.

### Fix: нечитаемый текст баннеров в светлых темах (Hello Kitty, Vision)

**Root cause:** баннеры ошибок и предупреждений, тосты, степпер и статусные подписи используют светлые оттенки текста (`text-red-100`, `text-amber-100`, `text-emerald-300` и т.п.), рассчитанные на тёмный фон; на светлом розовом фоне текст практически исчезал.

- Для светлых тем светлые оттенки (100–400) перекрашиваются в тёмные 700-уровня — глобально, без правки компонентов. Тёмные темы не затронуты.
