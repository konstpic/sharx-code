## Release v1.9.0

**Release Date:** September 24, 2026

Релиз **v1.9.0** относительно **v1.8.0**: наглядные карточки-превью вместо выпадающих списков в нескольких местах панели, нагрузка и ядра в плитках нод, исправление подложек на стеклянных карточках.

**Миграция БД:** нет.

---

### Feature: карточки-превью выбора

- **Тема панели** (Настройки → Панель и общее): галерея из 10 тем, каждая показана миниатюрой панели с настоящими цветами. Палитры превью генерируются при сборке из CSS тем, поэтому не расходятся с ними.
- **Цветовая палитра страницы подписки** (Настройки → Подписка и JSON): карточки с мини-макетом клиентской страницы подписки в цветах пресета.
- **Создание инбаунда по сценарию:** в форме нового подключения пять карточек — «Обход блокировок» (VLESS + Reality, ключи создаются автоматически), «Максимальная скорость» (Hysteria 2), «За CDN или прокси» (VLESS + XHTTP + TLS), «Широкая совместимость» (Trojan + TLS), «Просто и легко» (Shadowsocks). Выбор заполняет протокол и транспорт, всё остаётся редактируемым; у каждого сценария приблизительные метки скрытности, скорости и совместимости.
- **Готовые правила маршрутизации** (конфигуратор Xray → Маршрутизация): пресеты «блокировать рекламу и трекеры», «блокировать BitTorrent», «локальная сеть напрямую», «Россия напрямую», «Китай напрямую». Правила вставляются перед правилом «всё остальное»; уже добавленные отмечаются.
- **Выбор версии ядра** (дашборд): карточки с поиском и пометками «Текущая», «Последняя», «новее», «старее».
- **Галерея шаблонов:** в карточках схема «протокол → транспорт → защита» (для конфигов ядра — число аутбаундов, правил и DNS-серверов). Для облачных шаблонов сводку считает сервис галереи (версия сервиса 0.4.0), для локальных — панель.

### Feature: ноды в режиме плиток

- В плитке CPU-график за последние минуты и полоски ОЗУ и диска с цветом по нагрузке. Данные берутся из существующей истории нагрузки, обновляются раз в 30 секунд только пока открыт режим «Плитки». История хранится в памяти сервера, после перезапуска панели наполняется заново.
- Ядра (Xray, Telemt, AmneziaWG) собраны в один блок одинаковых строк: название, состояние, версия, кнопки «Остановить» и «Перезапустить» одного размера; версия Worker в шапке блока.
- Подключения ноды показаны чипами (первые три и «+N» с раскрытием).

### Fix: вложенные блоки на стеклянных карточках

В светлых стеклянных темах (Vision, Hello Kitty) вложенные блоки выглядели белыми «наклейками». Теперь для них используются полупрозрачные подложки, подхватывающие цвет стекла.
