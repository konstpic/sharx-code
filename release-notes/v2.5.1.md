## Release v2.5.1

**Release Date:** October 7, 2026

Доработки журналов v2.5.0: журнал читает весь лог и архивы, меньше шума, безопасный DEBUG у балансировщика.

**Миграция БД:** нет.
**Изменения API:** нет.
**Обновление:** панель и агент балансировщика (образ `sharxbalancer`) вместе.

### Журнал

- Журнал читает весь текущий файл логов и, если период уходит глубже, ротированные `.gz`-архивы (раньше это планировалось читать только хвостом). Разбор инкрементальный: каждый запрос обрабатывает только дописанное, архивы кэшируются, потолок кэша 400 000 записей.
- Исправлено: фильтр «минимальный уровень» не применялся к записям из буфера.
- xray: строки `Connection closed immediately, likely health check connection` (пробы балансировщика, по строке каждые 3 секунды на участника) скрыты в журнале нод.

### Балансировщик

- DEBUG (строка на каждое закрытое соединение) сам возвращается в INFO через час, чтобы забытый переключатель не раздувал логи.
- Вывод AmneziaWG/Telemt/движка больше не дублируется «сырой» копией в stderr контейнера.
- Для обычной ротации ничего не меняется: файловые логи по-прежнему ограничены 50 МБ × 5 архивов. Лимиты Docker-логов не настраиваются.
