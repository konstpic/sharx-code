## SharX v2.13.5

- Панель загружает устройства и привязки клиентов к inbound пакетно, сохраняя их порядок и признаки блокировки.
- При обновлении матрицы трафика по WebSocket панель опрашивает воркеры один раз за цикл. Каждый пользователь получает строки своих клиентов. Итоги для сортировки вычисляются один раз.
- Карточка клиента загружает подключения пачками и строит план bundle-хостов один раз. Ссылки возвращаются в порядке назначений.
- Учёт трафика возвращает ошибку при отказе PostgreSQL на COMMIT. Отключение клиентов по лимитам запускается после успешного коммита.
- Исправлена гонка при одновременной проверке нескольких выходных нод mesh.
