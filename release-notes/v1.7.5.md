## Release v1.7.5

**Release Date:** July 23, 2026

Патч **v1.7.5** относительно **v1.7.4**: полнота документации Panel API.

**Миграция БД:** нет.

---

### Documentation

- **Panel API reference** (`web/docs/API.md`)
  - Добавлены ранее недокументированные эндпоинты: inbound preview/TLS, Telemt/docker updater/logs, secret paths / 2FA / UI prefs / subscription page config, node sidecars и geography, client links & session block, group bulk ops, DB Inspector, public subscription API, Prometheus `/panel/metrics`.
  - Исправлена секция Node Push: `push-logs` / `push-geo` / `pull-xray-config` — auth через `X-Sharx-Signature: v1=…` (HMAC), не `apiKey`.
  - Новые секции документа: **20. Public Panel API**, **21. DB Inspector**, **22. Prometheus Metrics**.

### Operational Notes

- Изменения только в markdown-документации; пересборка образа не обязательна, если не используете встроенную страницу **API docs** в panel UI.
