## Release v1.7.14

**Release Date:** September 17, 2026

Патч **v1.7.14** относительно **v1.7.13**: добавляет две декоративные темы панели — **Hello Kitty** и **Barbie** — и завершает поддержку Telemt WEB-режима в subscription-ссылках и decoy-конфигурации.

**Миграция БД:** нет.

---

### UI changes

- **Hello Kitty** — светлая пастельная pink/blue тема с округлой типографикой Comfortaa, мягким свечением, мотивами бантиков и анимированным полем следов лапок.
- **Barbie** — тёмная глянцевая pink/gold тема с Playfair Display, блёстками, glow-эффектами и деликатным shimmer-анимацией.
- Обе темы доступны в **Panel settings → Appearance → Theme**, используют существующую оболочку панели (navbar, sidebar, surfaces и dashboard) и корректно учитывают `prefers-reduced-motion`.
- Добавлены названия тем во все сгенерированные локали панели; на русском название Vision остаётся «Жидкое стекло».

### Fixes

- **Telemt WEB subscription links** (`sub/telemt_tg.go`, `sub/subService.go`, subscription UI)
  - Для WEB-инбаунда теперь выдаётся Telegram-ссылка `tg://webproxy?...` вместо обычной TCP MTProxy-ссылки `tg://proxy?...`.
  - Неполная WEB-конфигурация не откатывается молча к TCP-ссылке: пока для WEB не заданы допустимый host и порт 443, ссылка не публикуется.
  - Подписочная HTML-страница и парсер WireGuard-конфига распознают оба формата ссылок.
- **Telemt WEB decoy mode** (`web/service/telemt_config.go`)
  - В сгенерированный TOML явно записывается `mode = "static_directory"` или `mode = "http_upstream"`; Telemt получает корректный режим приманки, а не только его параметры.

### Operational Notes

- Для Telegram WEB proxy нужен публичный HTTPS на **443** и настроенный `vhostHost`; это ограничение формата `tg://webproxy`, в ссылке нет поля порта.
- Обновите оба образа — **sharx** содержит UI, генерацию subscription-ссылок и конфиг Telemt; **sharxnode** остаётся рекомендованным для одинаковой версии всей установки.

### Test plan

- [ ] Выбрать Hello Kitty и Barbie в настройках панели → тема сразу применяется, сохраняется после перезагрузки и не нарушает navigation/sidebar/dashboard.
- [ ] Включить `prefers-reduced-motion` → фоновые анимации тем не проигрываются.
- [ ] Создать Telemt WEB-инбаунд с доменом и `frontPort: 443` → в HTML-подписке появляется `tg://webproxy?server=<host>&secret=<secret>`.
- [ ] Задать WEB-инбаунду неполный host либо порт, отличный от 443 → TCP-ссылка вместо WEB-ссылки не появляется.
- [ ] `go test ./sub/... ./web/service/...` — зелёные, включая генерацию WEB proxy-ссылки и TOML decoy modes.
