## Release v1.7.10

**Release Date:** September 14, 2026

Патч **v1.7.10** относительно **v1.7.9**: AmneziaWG 3.1 параметры + актуальный минимум Header Protection, Telemt обновлён до 3.5.7 с новыми параметрами `[server]`/`[server.api]`.

**Миграция БД:** нет (новые поля в JSON `inbounds.settings`).

---

### Features

- **AmneziaWG 3.1** (`web/service/amneziawg_config.go`, `panel/lib/amneziawgInbound.ts`, `panel/components/InboundsPage.tsx`)
  - `RandomTrailers` и `DisableCookies` (bool, пишутся в `.conf` только когда включены)
  - Минимум `S1`–`S4` для `HeaderProtectionKey` поднят с 8 до 12 вслед за upstream amneziawg-go (`HeaderCipherNonceSize`)
- **Telemt 3.5.7** (было 3.4.18) (`DockerInit.sh`, `web/service/telemt_config.go`, `panel/lib/inboundDefaults.ts`, `panel/components/InboundsPage.tsx`)
  - `server.metrics_listen`, `server.metrics_whitelist`
  - `server.api.minimal_runtime_enabled`, `server.api.minimal_runtime_cache_ttl_ms`

### Operational Notes

- После обновления пересоберите/перезапустите **sharx** и **sharxnode** (образ тянет свежий `amneziawg-go`/`amneziawg-tools` master и Telemt 3.5.7).
- Миграция БД не требуется.
- Существующие AmneziaWG inbound с `HeaderProtectionKey` и `S1`–`S4` в диапазоне 8–11 перестанут проходить валидацию при следующем сохранении — поднимите `S1`–`S4` до ≥ 12 в UI.
- Telemt inbound без новых полей (`metricsListen`, `metricsWhitelist`, `minimalRuntimeEnabled`, `minimalRuntimeCacheTtlMs`) генерируют TOML без изменений — поля опциональны.

### Test plan

- [ ] AWG inbound: `RandomTrailers`/`DisableCookies` в UI → только заданные попадают в `.conf`
- [ ] `HeaderProtectionKey` + `S1`–`S4` < 12 → ошибка валидации с новым порогом
- [ ] `HeaderProtectionKey` + `S1`–`S4` ≥ 12 → как раньше
- [ ] Legacy AWG inbound без новых полей — conf не изменился
- [ ] Telemt inbound: новые поля в UI → соответствующие ключи в `config.toml`, пустые поля не пишутся
- [ ] Свежая нода тянет Telemt 3.5.7 (`DockerInit.sh`)
- [ ] Worker с новым sharxnode поднимает AWG sidecar с новым `awg`/`amneziawg-go`
