# SharX v2.14.2-beta

- Fixed network enrollment errors being reported as successful requests awaiting confirmation. A valid invitation activates participation immediately.
- Fixed JSON request handling for network node publishing, limits, pause/unpublish, participation settings and session actions.
- Fixed the public endpoint host from the publication form being ignored.
- Added SHARX_NETWORK_PORT_MIN and SHARX_NETWORK_PORT_MAX for deployments exposing a restricted inclusive port range.
- Updated the Go toolchain, compression/network dependencies and Alpine runtime packages required by release security checks.

Container images:
- harbor.sharxconnect.app/sharx/sharx:2.14.2-beta
- harbor.sharxconnect.app/sharx/sharxnode:2.14.2-beta
- harbor.sharxconnect.app/sharx/sharxbalancer:2.14.2-beta

This is a beta release for testing.
