## Release v1.7.23

**Release Date:** September 19, 2026

Релиз **v1.7.23** относительно **v1.7.22**: закрыт обход ограничения устройств через отключение HWID в клиенте и добавлены настраиваемые замечания для заблокированных приложений вместо голого HTTP 403 (по обратной связи сообщества).

**Миграция БД:** нет.

---

### Fix: отсутствие HWID больше не обходит ограничение устройств

**Root cause:** `registerHWIDFromRequest` при пустом заголовке `x-hwid` просто возвращала `nil` — подписка выдавалась без какой-либо проверки. Достаточно было отключить передачу HWID в клиенте (например, Incy), чтобы лимит устройств переставал действовать.

- Если у клиента включено ограничение HWID и глобальный режим HWID равен `client_header`, отсутствие (или пустое/из одних пробелов) значение `x-hwid` теперь отдельное состояние `ErrHWIDMissing`, а не «всё хорошо».
- Клиент получает замечание «HWID: нет идентификатора устройства» (ключ `HWIDNotSupported`, ранее не использовался); при выключенных замечаниях — 403. Работает для обычной и `/json/` подписки.
- Отдельного параметра нет: поведение управляется существующими включателями — режим HWID `off` или выключенное ограничение HWID у клиента полностью отключают проверку, у таких клиентов ничего не меняется.
- **Важно:** клиенты с включённым HWID, использующие приложения без поддержки HWID (например, v2rayNG), теперь не получат подписку — это и есть смысл включённого ограничения.

### Feature: замечания подписки для заблокированных приложений

- Вместо безусловного 403 при блокировке по приложению клиент получает текстовое замечание из редактора «Замечания подписки». Добавлены два новых поля: «Заблокированное приложение» (`blockedApp`) и «Нераспознанное приложение» (`unknownApp`). Тексты меняются в интерфейсе панели без правки кода.
- Если замечания выключены или поле очищено, поведение прежнее — 403.
- Найдено попутно и исправлено: проверка приложения не применялась к `/json/`-подписке — теперь применяется.
- Убрана устаревшая подпись «(пока не используется)» у поля HWID в редакторе замечаний (все локали).
