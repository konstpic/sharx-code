## Release v1.7.21

**Release Date:** September 18, 2026

Патч **v1.7.21** относительно **v1.7.20**: добавил переводы для новых настроек из прошлого релиза — часть текста в UI оставалась на английском.

**Миграция БД:** нет.

---

### Root cause

Новые строки UI для ретеншена геофайлов, recency-окна IP-лимита и гейта подписки (v1.7.20) были добавлены в компоненты через `t(key, { defaultValue: "английский текст" })` без соответствующих записей в `web/translation/*.toml` — источнике истины для локалей. Раз ключа не было ни в одном TOML, `gen-locales.mjs` не мог его сгенерировать, и i18next показывал английский `defaultValue` для всех языков, включая русский.

### Fixes

- Добавлены ключи в `web/translation/translate.en_US.toml` и `translate.ru_RU.toml`:
  - `pages.xray.geoRetentionCount(Desc)`
  - `pages.settings.ipLimitRecencyWindow(Desc)`
  - `pages.settings.subAppGateEnable(Desc)`, `subAppGateRequireKnownApp(Desc)`, `subAppGateBlockedApps(Desc)`
- `panel/public/locales/*.json` пересобраны через `gen-locales.mjs` из TOML (не редактировались вручную).
- Остальные 11 языков (кроме en/ru) официальных переводов для этих ключей пока не имеют — i18next откатывается на английский текст через `fallbackLng`, как и для прочих недавно добавленных строк в этой кодовой базе.

### Test plan

- [x] `go build ./...` — чисто.
- [x] Проверено, что новые ключи реально попали в `panel/public/locales/en.json` и `ru.json` после регенерации (сверено построчно).
- [ ] После выката: открыть Settings и Xray → Geo-files на русской локали → все подписи на русском, без английских вставок.
