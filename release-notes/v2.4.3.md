## Release v2.4.3

**Release Date:** October 3, 2026

Релиз **v2.4.3** относительно **v2.4.2**: исправлена автоустановка ноды и балансировщика на голый Debian 13, где она ошибочно отказывала под root.

**Миграция БД:** нет.
**Изменения API:** нет.
**Обновление:** достаточно обновить панель.

---

### Fix: «SSH user "root" is not root»

- В v2.4.2 проверка прав читала текст вывода `id -u`. На чистом сервере к выводу команды примешивается шум (предупреждения о локали, баннер), и root определялся как обычный пользователь: установка останавливалась на шаге «Проверка Docker» с ошибкой «not root and passwordless sudo is not available».
- Теперь root определяется по коду возврата команды, а не по тексту; логин `root` всегда считается root.
- Проверено на чистом Debian 13 (нет `curl`, `sudo`, `git`): проверка root проходит, скрипт доустанавливает `curl`, установщик Docker распознаёт Debian 13 и планирует `docker-ce` с плагином compose.
- Для не-root пользователя без беспарольного sudo поведение прежнее: понятная ошибка с подсказкой подключиться под root.
