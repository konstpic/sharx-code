## Release v1.6.7

**Release Date:** July 1, 2026

Патч **v1.6.7** относительно **v1.6.6**: подписка для Throne, доработки Shadowsocks, UI маршрутизации и объявлений, сброс трафика нод, порт worker через env.

**Миграция БД:** `0048_node_traffic_reset_day.sql` — колонка `nodes.traffic_reset_day` (0 = выкл, 1–31 = день месяца).

---

### Bug Fixes

- **Подписка Throne / nekobox-like (Windows)** (`sub/ua_dispatch.go`, `sub/subscription_filter.go`, `sub/subController.go`)
  - **Симптом:** в Throne подтягивался только AmneziaWG/WG-блок или Clash YAML без Xray-ссылок; на версиях без Amnezia конфиг вставал как WireGuard.
  - **Фикс:** UA `throne` обрабатывается **до** `clash` → base64 share links; из ответа для Throne убраны wg-quick / AmneziaWG блоки.

- **Shadowsocks (остаточные кейсы после v1.6.6)** (`web/service/inbound.go`, `web/service/client_key_rotation.go`)
  - Санитизация SS settings при **создании** inbound.
  - `ResetClientTraffic`: для SS2022 в AddUser не передаётся `method` (пустой cipher).
  - `RotateAllClientKeys`: ключи SS2022 генерируются с правильной длиной по методу инбаунда.

- **Конструктор маршрутизации (Sites/IPs)** (`panel/components/settings/subscription/RoutingProfilesEditor.tsx`)
  - **Симптом:** Enter / Shift+Enter не добавляли новую строку — `linesToList` сразу удалял пустые строки.
  - **Фикс:** локальный state в textarea, список обновляется на blur.

### Features

- **Объявление в подписке** (`panel/components/settings/subscription/ResponseRulesEditor.tsx`, `web/service/subscription_response_rules.go`, `sub/subController.go`, `sub/happ_meta.go`)
  - Textarea с лимитом 200 символов (как у клиента).
  - Заголовок `Announce` отдаётся клиентам в формате `base64:…` (UTF-8).

- **Сброс трафика нод по дню месяца** (`database/migrations/0048_node_traffic_reset_day.sql`, `database/model/model.go`, `panel/components/NodesPage.tsx`, `web/job/node_traffic_reset_job.go`, `web/service/node.go`)
  - Поле **Traffic reset day** в настройках ноды: 0 = выкл, 1–31 = сброс счётчиков в этот день каждого месяца (cron `@daily`).

- **Порт sharx-node через env** (`node/main.go`, `node/README.md`)
  - `SHARX_NODE_PORT` или `PORT` переопределяют флаг `-port` (по умолчанию 8080).

### Operational Notes

- Обновляется **панель (`sharx`)** и рекомендуется **`sharxnode`** (новые env для порта).
- После деплоя panel: миграция применится автоматически; пересборка Docker (`docker compose build sharx sharxnode && docker compose up -d --force-recreate sharx sharxnode`).
- Клиентам Throne с Amnezia-only inbound в подписке останутся только Xray-протоколы; WG/AWG — через отдельные каналы (QR / .conf).
