## Release v1.7.4

**Release Date:** July 23, 2026

Патч **v1.7.4** относительно **v1.7.3**: расширенные настройки Telemt, исправление смешанных подписок с AmneziaWG для INCY и навигация панели при секретном `webBasePath`.

**Миграция БД:** `0050_client_inbound_telemt_ad_tag.sql` — колонка `telemt_ad_tag` в `client_inbound_mappings`.

---

### Features

- **Расширенная форма Telemt** (`panel/components/InboundsPage.tsx`, `panel/lib/inboundDefaults.ts`, `web/service/telemt_config.go`)
  - Дополнительные параметры general / network / timeouts / censorship / access в UI (свёрнутые секции).
  - Значения сохраняются в JSON настроек inbound и попадают в генерируемый `config.toml` (пустые поля не эмитятся).

- **Per-client AD tag для Telemt** (`0050_client_inbound_telemt_ad_tag.sql`, `panel/components/ClientsPage.tsx`, `web/service/client.go`)
  - Поле AD tag на mapping клиент ↔ inbound; секция `[access.user_ad_tags]` в TOML.

### Documentation

- **Panel API reference** (`web/docs/API.md`)
  - Добавлены ранее недокументированные эндпоинты: inbound preview/TLS, Telemt/docker updater/logs, secret paths / 2FA / UI prefs / subscription page config, node sidecars и geography, client links & session block, group bulk ops, DB Inspector, public subscription API, Prometheus `/panel/metrics`.
  - Исправлена секция Node Push: `push-logs` / `push-geo` / `pull-xray-config` — auth через `X-Sharx-Signature: v1=…` (HMAC), не `apiKey`.

### Bug Fixes

- **Смешанная подписка INCY + AmneziaWG** (`sub/subscription_filter.go`, `sub/subController.go`)
  - URI-list клиенты (INCY, v2rayNG, Hiddify, Nekobox и др.) получают WG/AWG как wg-quick блок с комментарием `# Inbound: …`.
  - Между записями подписки — `\n\n`, чтобы многострочный AWG не «съедал» остальные inbound.
  - Throne по-прежнему отбрасывает WG-блоки целиком.

- **Меню панели после смены секретного path** (`web/panel_fs.go`, `panel/components/panel/PanelNavLink.tsx`, `panel/components/panel/PanelShell.tsx`, `panel/lib/paths.ts`)
  - При runtime `webBasePath` пункты меню используют полную перезагрузку страницы (Next client router не умеет RSC fetch под секретным префиксом).
  - RSC flight `.txt` переписываются с префиксом для `/_next/` ассетов.
  - Нормализация pathname для активного пункта меню; client-side redirect на `/panel/settings/…`.
  - Обновлён статический экспорт `web/panel/` — добавлены маршруты statistics, geography, settings tabs, db-inspector, xray/geo.

### Operational Notes

- После обновления до **1.7.4** пересоберите/перезапустите **panel** (`sharx`) — UI встроен в образ.
- Миграция `0050` применяется автоматически при старте.
- Для multi-node workers обновление **sharxnode** не обязательно, если не меняли Telemt на нодах.
