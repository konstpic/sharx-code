### Fix: нет IP в активных сессиях у клиентов AmneziaWG

Клиент с AmneziaWG-инбаундом горел «Онлайн» в списке, но в модалке «Активные сессии» было «Нет активных IP». AmneziaWG — sidecar вне Xray, поэтому статистика `user>>>email>>>online` для него всегда пуста, а обработчик `/api/v1/user-online-sessions` на ноде опрашивал только Xray и Telemt. Endpoint пира из `awg show <iface> dump` парсер не читал.

**Fix:**
- Нода читает endpoint пира из `awg show dump` и отдаёт его IP в сессиях (протокол `amneziawg`, remark — тег инбаунда).
- Показываются только пиры с handshake не старше 180 с — то же окно, что у флага «онлайн».
- Ограничение: Block для IP AWG-сессии действует только через блоклист подписки; роутинг Xray и conntrack-drop на трафик AWG не влияют.
