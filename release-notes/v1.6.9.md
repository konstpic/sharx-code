## Release v1.6.9

**Release Date:** July 1, 2026

Патч **v1.6.9** относительно **v1.6.8**: секретные URL-префиксы для панели и подписок, hotfix модалки обновления Docker.

**Миграция БД:** не требуется.

---

### Bug Fixes

- **Модалка обновления Docker: ложный «Сбой» панели** (`panel/components/panel/DockerUpdateProgressModal.tsx`)
  - Health-check нод вызывал несуществующий `/panel/api/node/check/:id` (404) → прерывался весь сценарий.
  - **Фикс:** корректный `POST /panel/node/check/:id`, устойчивый poll, текст ошибки trigger под нодой.

### Features

- **Секретные пути URL (панель + подписка)** (`util/secretpath`, `web/web.go`, `web/panel_fs.go`, `web/service/setting.go`, `panel/components/SettingsPage.tsx`, `panel/lib/paths.ts`)
  - Генерация случайных префиксов `webBasePath` и опционально `subPath` из настроек (**Панель и общее → Секретные пути URL**).
  - **Ручной ввод** префиксов и переключатель «только панель» (без смены `subPath` и ссылок подписок).
  - `https://host:port/` без префикса → **HTTP 404** (без редиректа на логин).
  - Логин: `https://host:port/{prefix}/`, дашборд: `…/{prefix}panel/`.
  - Подписка: `https://sub-host:2096/{prefix}{subId}` (голый `:2096/` по-прежнему 404).
  - HTML и `window.__SHARX_BASE_PATH__` подставляются на лету — **пересборка образа с другим `NEXT_PUBLIC_BASE_PATH` не нужна**.
  - Не срабатывает, если заданы `XUI_WEB_BASE_PATH` / `XUI_SUB_PATH` в env (приоритет env).

### Operational Notes

- После генерации путей **обязателен перезапуск панели**; сохраните новый URL входа — без префикса панель не откроется.
- Если изменился `subPath`, клиентам может понадобиться обновить ссылки подписки.
- Существующие установки с `webBasePath: /` работают как раньше, пока не включите секретные пути.

### 📦 Upgrade from v1.6.8

1. Бэкап `.env` и БД.
2. Обновите **`sharx`** до **`1.6.9`** / **`latest`**.

```yaml
services:
  sharx:
    image: {{SHARX_TAG_LATEST}}
  sharxnode:
    image: {{SHARXNODE_TAG_LATEST}}
  postgres:
    image: {{HARBOR_HOST}}/{{HARBOR_PROJECT}}/postgres:latest
```

3. (Опционально) **Настройки → Панель и общее → Секретные пути URL** → сгенерировать → перезапуск → сохранить новый URL.
