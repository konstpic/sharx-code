# SharX v2.14.0-beta

Closed beta of SharX Network on top of the current main branch (including v2.13.0 mesh and subsequent fixes).

- Participant onboarding by invitation, node publication, network catalogue, session provisioning and credit views.
- Dedicated network inbound, persistent signed worker counters, Linux bandwidth enforcement and service-only verification probes.
- Operator tariff snapshots, integer credit quotes and display of the seven-day 100% earnings hold.
- Coordinator implementation and accounting backend are maintained and deployed separately from this public repository.

**Network access is currently granted on request by the operator. / Доступ к сети пока предоставляется по запросу оператору.** Installing the beta does not grant access automatically.

This is a prerelease for invited testing. The independent witness registry must be configured before paid assignments are enabled. A software worker counter and reachability probes do not prove every customer byte against a malicious host or colluding endpoints. No claim of complete fraud prevention or completed pre-core attestation is made.
