## Release v2.4.2

**Release Date:** October 3, 2026

Релиз **v2.4.2** относительно **v2.4.1**: исправлены два дефекта автоустановщика ноды и балансировщика по SSH.

**Миграция БД:** нет.
**Изменения API:** да, необязательное поле `nodePort` в `POST /panel/node/ssh-provision`.
**Обновление:** достаточно обновить панель.

---

### Fix: автоустановка на «голый» сервер

- **Docker не ставился на чистом Debian, а ошибка терялась.** Установка шла через `curl … | sh`: на чистом сервере нет `curl` и `wget`, а конвейер сообщал об успехе даже при неудачной загрузке. Теперь установщик при необходимости доустанавливает `curl` (apt, dnf, yum, apk, zypper), скачивает скрипт в файл и запускает его, затем проверяет, что демон Docker отвечает и плагин compose на месте.
- **Не-root пользователь.** Привилегированные команды (установка Docker, создание каталога, `docker compose`) выполнялись без sudo. Теперь установщик определяет пользователя: root работает как раньше, пользователь с беспарольным sudo — через `sudo -n`, иначе сразу понятная ошибка «пользователь не root и sudo недоступен».
- **Сообщение об ошибке** показывает конец вывода команды (там настоящая причина), а не начало.
- Исправление действует и для ноды, и для балансировщика.

### Fix: порт ноды не попадал в compose

- Автоустановщик ноды не добавлял в `docker-compose.yml` переменную `SHARX_NODE_PORT`, поэтому нода всегда слушала 8080, а панель регистрировала её под введённым портом. Теперь для порта не 8080 переменная добавляется; то же сделано для ручной копии compose.
- Фронтенд мог отправить устаревшее значение порта (не отслеживал поле в коллбэке установки): исправлено.
