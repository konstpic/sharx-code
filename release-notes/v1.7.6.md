## Release v1.7.6

**Release Date:** July 27, 2026

Патч **v1.7.6** относительно **v1.7.5**: совместимость подписок с INCY (AmneziaWG / WireGuard / Hysteria2), per-node `serverDescription`, исправления TLS pin в JSON-подписке, secret-path panel и drop для offline-сессий.

**Миграция БД:** `0051_inbound_node_server_description.sql` — колонка `server_description` в `inbound_node_mappings`.

---

### Features

- **Per-node server description** (`0051_inbound_node_server_description.sql`, `panel/components/InboundsPage.tsx`, `panel/components/HostsPage.tsx`, `sub/share_link_fragment.go`)
  - Поле «Описание сервера» (до 30 символов) на binding inbound ↔ node.
  - В share-ссылках fragment формата INCY/Happ: `#Name?serverDescription=<base64>`.
  - Применяется к VLESS / VMess / Trojan / SS / Hysteria2 и к `amneziawg://` / `wireguard://`.

### Bug Fixes

- **INCY: смешанная подписка AWG + URI** (`sub/share_link_wireguard.go`, `sub/subscription_filter.go`)
  - Panel `.conf` для URI-list клиентов конвертируется в `amneziawg://<base64url-conf>#Name` или `wireguard://…` вместо сырого wg-quick текста.
  - Устраняет ошибку `awg: unknown [Peer] key "hysteria2://…"` при mixed-подписке.

- **Hysteria2 share-links для INCY** (`sub/subService.go`, `sub/share_link_tls.go`)
  - Убран лишний query-параметр `security=tls` (не в спеке INCY).
  - Пароль в URL кодируется через `url.User()` — спецсимволы больше не ломают ссылку.
  - TLS pin только через `pinSHA256` (без дублирующего `pcs`).

- **TLS pin в JSON-подписке** (`xray/tls_sanitize.go`, `sub/stream_settings.go`, `sub/subJsonService.go`)
  - `pinnedPeerCertSha256` больше не попадает в outbound как JSON-array — только строка, как ожидает INCY full Xray JSON.

- **Secret-path panel: ChunkLoadError в редакторе профилей** (`web/web.go`, `web/panel_fs.go`, `panel/components/xray/XrayConfigTemplateEditor.tsx`)
  - `/_next/` и locales доступны также с корня сайта при секретном `webBasePath` (Monaco / dynamic imports).

- **Drop для offline blocked sessions** (`web/service/client_session.go`)
  - Кнопка «Disconnect» больше не всегда disabled для IP из «Blocked IPs (not in live stats)`.

### Operational Notes

- После обновления до **1.7.6** пересоберите/перезапустите **sharx** (panel + sub API в образе).
- Миграция `0051` применяется автоматически при старте.
- Клиентам INCY: обновить подписку (pull-to-refresh) после деплоя.
- **sharxnode** обновление не обязательно, если не меняли worker-конфигурацию.

### 📦 Upgrade from v1.7.5

1. Бэкап БД (новая колонка `server_description`).
2. Обновите **`sharx`** до **`1.7.6`** / **`latest`**.

```yaml
services:
  sharx:
    image: {{SHARX_TAG_LATEST}}
```

3. Перезапуск контейнера — миграция и новый UI подхватятся автоматически.
4. При необходимости задайте «Описание сервера» на binding inbound ↔ node в панели.
