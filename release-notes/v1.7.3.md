## Release v1.7.3

**Release Date:** July 3, 2026

Патч **v1.7.3** относительно **v1.7.2**: исправление «тихого» падения inbound после hot-path `update-inbound` в multi-node.

**Миграция БД:** нет.

---

### Bug Fixes

- **Hot-path `update-inbound`: wire-format / rollback failure**
  - Панель собирает JSON для API через `PreviewInboundCoreConfig` (те же transforms, что и full worker config) — без лишних полей `created_at` / `enable` в clients.
  - Нода валидирует inbound JSON через `conf.Build()` **до** `DelInbound`.
  - Если `AddInbound` не удался и rollback тоже упал — нода **перезапускает Xray** из сохранённого конфига (восстановление runtime).
  - Fallback панели на `apply-config` после ошибки API отправляет `forceReload: true`, чтобы не попасть в `skip-restart` при расхождении runtime и snapshot конфига (регрессия v1.7.1).

### Operational Notes

- После обновления до **1.7.3** обновите **и panel, и sharxnode** на затронутых worker-нодах.
- `expectedConfigSha256 mismatch` по-прежнему только warning — на apply не влияет.
