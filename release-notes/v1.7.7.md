## Release v1.7.7

**Release Date:** July 27, 2026

Патч **v1.7.7** относительно **v1.7.6**: AmneziaWG 3.0 параметры (с legacy) и workaround для INCY Hysteria2 `pinSHA256`.

**Миграция БД:** нет (AWG 3 поля в JSON `inbounds.settings.obfuscation`).

---

### Features

- **AmneziaWG 3.0** (`web/service/amneziawg_config.go`, `panel/lib/amneziawgInbound.ts`, `panel/components/InboundsPage.tsx`)
  - `HeaderProtectionKey` (server-side; при ключе S1–S4 поднимаются до ≥ 8)
  - `ContentPaddingAddition` (число или range `min-max`)
  - Timings: `RekeyAfterTime`, `RekeyTimeout`, `RejectAfterTime`, `KeepaliveTimeout`, `MaxHandshakeAttempts`
  - Signature packets `I1`–`I5`
  - `S3` / `S4` в UI; `H1`–`H4` — число или range (`10-99`)
  - Пустые AWG 3 поля не пишутся в `.conf` — существующие inbound и старые клиенты без изменений
  - Legacy JSON с `"h1": 999` (int) по-прежнему парсится

### Bug Fixes

- **INCY + Hysteria2 pinSHA256** (`sub/subscription_filter.go`)
  - Для UA INCY с hy2-ссылок убирается `pinSHA256`, ставится `insecure=1`
  - Обход бага INCY: `pinSHA256` → `pinnedPeerCertSha256` как JSON-array при ожидании string в Xray
  - Другие клиенты по-прежнему получают pin

### Operational Notes

- После обновления пересоберите/перезапустите **sharx** и **sharxnode** (образ собирает `amneziawg-go` из upstream master — AWG 3 на нодах).
- Миграция БД не требуется.
- Для Header Protection: задайте ключ в inbound → Apply → обновите подписку у клиентов с AWG 3.
- INCY: обновить подписку после деплоя, чтобы Hy2 пришёл без `pinSHA256`.

### Test plan

- [ ] Legacy AWG inbound без новых полей — conf и подписка как раньше
