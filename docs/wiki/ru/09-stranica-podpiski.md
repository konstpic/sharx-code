# 9. Страница подписки

## Два уровня подписки

SharX разделяет подписку на два уровня:

| Уровень | Адрес | Для кого |
|---------|-------|----------|
| **Эндпоинт подписки** | `https://домен:2096/sub/<subId>` | Клиентские приложения (Happ, v2rayNG, Clash…) |
| **Публичная страница** | `https://домен-панели/panel/sub/?id=<subId>` | Браузер конечного пользователя |

Когда пользователь открывает ссылку подписки **в браузере** (User-Agent с `text/html`), панель перенаправляет его на публичную страницу. Приложения получают конфигурацию в машиночитаемом формате.

Параметр `?legacy=1` отключает редирект на публичную страницу.

## Форматы ответа по клиенту

Панель определяет формат по User-Agent:

| Клиент | Формат |
|--------|--------|
| **Happ** | Зашифрованный JSON |
| **v2rayTun** | Зашифрованный JSON |
| **v2rayNG, Hiddify, Streisand, Shadowrocket, Karing, Nekobox** | Base64 |
| **Clash / Mihomo** | Clash YAML |
| **sing-box** | Xray JSON |
| **INCY** | Base64 |
| **Браузер** | Редирект на публичную страницу |

Принудительный формат: `?format=clash` или `?format=mihomo`.

## Настройка конструктора (пошагово)

### Шаг 1. Брендинг

1. **Настройки → Подписка**.
2. Вкладка **Брендинг**:
   - **Название** — имя сервиса (`MyVPN`, `SharX Net`);
   - **Логотип** — URL PNG/SVG (например, `https://example.com/logo.png`);
   - **Цвета** — основной, фон, акцент (подберите контраст для тёмной/светлой темы);
   - **Favicon** — иконка вкладки браузера.
3. Справа — **предпросмотр** страницы.

### Шаг 2. Блоки

Вкладка **Блоки** → добавьте и упорядочьте:

| Рекомендуемый порядок | Блок |
|----------------------|------|
| 1 | `subscription-info` — трафик, срок, статус |
| 2 | `add-to-app` — кнопки импорта в Happ / v2rayTun |
| 3 | `links-list` — список серверов с QR |
| 4 | `installation-guide` — инструкция установки |
| 5 | `support-cta` — ссылка на поддержку |

Перетаскивайте блоки для изменения порядка.

### Шаг 3. Правила ответа

Вкладка **Правила ответа**:

| Поле | Пример | Зачем |
|------|--------|-------|
| Profile-Title | `MyVPN Premium` | Имя в Happ |
| Profile-Update-Interval | `12` | Обновление каждые 12 ч |
| Announce | `Сервер обновлён 01.06` | Уведомление в приложении |
| Support-Url | `https://t.me/support` | Кнопка поддержки |
| providerid | UUID провайдера | Для Happ app-management |

### Шаг 4. Пользовательские примечания

Вкладка **Пользовательские примечания** — тексты при блокировке:

```
Истёк срок: «Подписка истекла. Напишите в поддержку.»
Лимит трафика: «Трафик исчерпан. Продлите тариф.»
HWID: «Превышен лимит устройств.»
```

Включите **Показывать пользовательские примечания**, если хотите скрывать реальные серверы при ограничении.

### Шаг 5. Сохранить

Кнопка **Сохранить** внизу конструктора. Проверьте страницу: откройте `/panel/sub/?id=<subId>` тестового клиента.

## Конструктор страницы подписки

Настройка: **Настройки → Подписка** (`/panel/settings/subscription/`).

Визуальный конструктор с вкладками:

### Брендинг

Оформление публичной страницы:

| Параметр | Описание |
|----------|----------|
| **Название** | Заголовок страницы |
| **Логотип** | URL изображения |
| **Цвета** | Основной, фон, акцент |
| **Шрифт** | Семейство шрифтов |
| **Favicon** | Иконка вкладки |

### Блоки

Конструктор из блоков — перетаскивание, изменение порядка:

| Блок | Описание |
|------|----------|
| **subscription-info** | Информация о подписке: трафик, срок, статус |
| **installation-guide** | Инструкция по установке клиентского приложения |
| **links-list** | Список ссылок / конфигов для импорта |
| **support-cta** | Кнопка связи с поддержкой |
| **custom-html** | Произвольный HTML |
| **metrics** | Метрики использования |
| **add-to-app** | Кнопки «Добавить в приложение» (deeplink) |

Каждый блок настраивается индивидуально (заголовок, видимость, параметры).

### Правила ответа (Response rules)

HTTP-заголовки и метаданные подписки для клиентских приложений:

| Параметр | Заголовок | Описание |
|----------|-----------|----------|
| **Название профиля** | `Profile-Title` | Имя подписки в приложении |
| **Интервал обновления** | `Profile-Update-Interval` | Как часто обновлять (часы) |
| **Объявление** | `Announce` | Текст уведомления |
| **URL поддержки** | `Support-Url` | Ссылка на поддержку |
| **Provider ID** | `providerid` | Идентификатор провайдера (Happ) |
| **Доп. параметры** | Произвольные заголовки | Любые meta-headers |
| **MTProto на странице** | — | Показывать MTProto на публичной странице |

Настройки доставки дополнительных заголовков: только в заголовках / только в теле / оба.

### Пользовательские примечания (Custom remarks)

Тексты-заглушки, которые показываются в подписке при определённых состояниях клиента:

| Состояние | Placeholder |
|-----------|-------------|
| Истёк срок | Текст для EXPIRED |
| Лимит трафика | Текст для LIMITED |
| Отключён | Текст для DISABLED |
| Нет хостов | Текст при отсутствии endpoint'ов |
| HWID: превышен лимит | `HWIDMaxDevicesExceeded` |
| HWID: нет ID устройства | `HWIDNotSupported` |

Переключатель **Показывать пользовательские примечания**:

- **Включён** — при ограничении показывается текст-заглушка вместо реальных серверов;
- **Выключен** — реальные ноды отдаются даже при ограничении.

## Публичная страница

URL: `/panel/sub/?id=<subId>`

Отображается без бокового меню панели — только контент, собранный в конструкторе.

Данные загружаются через API: `GET /panel/api/public/subscription`.

### Что видит пользователь

- Брендинг (логотип, цвета);
- Статус подписки (активна / истекла / лимит);
- Оставшийся трафик и срок;
- Список серверов с кнопками Import / QR / Copy;
- Инструкции по установке;
- Кнопки «Добавить в Happ» / «Добавить в v2rayTun» и др.;
- Конфиги AmneziaWG (.conf) для импорта в AmneziaVPN.

## Предпросмотр

В конструкторе есть **предпросмотр** — отображение страницы с тестовым Sub ID без публикации.

## Сохранение

Кнопка **Сохранить** записывает конфигурацию в базу данных. Изменения применяются ко всем клиентам (конфигурация страницы общая; данные клиента подставляются по `subId`).

## Ссылка подписки для клиента

Формируется из настроек:

```
https://<XUI_SUB_DOMAIN>:<XUI_SUB_PORT><XUI_SUB_PATH><subId>
```

Пример:

```
https://sub.example.com:2096/sub/a1b2c3d4e5f6g7h8
```

Sub ID уникален для каждого клиента и отображается в форме редактирования.

## Рекомендации

1. Настройте **брендинг** перед передачей ссылок клиентам.
2. Добавьте блок **installation-guide** с инструкцией для вашего клиентского приложения.
3. Используйте **add-to-app** для deeplink-импорта в Happ / v2rayTun.
4. Настройте **response rules** для корректного отображения в Happ (Profile-Title, providerid).
5. **Custom remarks** — информируйте пользователя о причинах блокировки понятным текстом.
