## Вход в панель

1. Откройте адрес панели в браузере (по умолчанию `http://сервер:2053`).
2. Введите логин и пароль администратора.
3. При включённой двухфакторной аутентификации (2FA) введите код TOTP или подтвердите через Telegram.

Сессия хранится в зашифрованных cookie — повторный ввод пароля не требуется до истечения сессии или выхода.

## Дашборд

Главная страница показывает:

- **Общий трафик** — загрузка и отдача за период.
- **Онлайн-клиенты** — количество активных подключений.
- **Состояние Xray** — запущен / остановлен / ошибка (в single-node режиме).
- **Состояние нод** — online/offline, Xray на каждой ноде (в multi-node).
- **Графики** — динамика трафика и подключений.

Данные обновляются в реальном времени через WebSocket.

## Настройки (вкладки)

| Вкладка | Содержание |
|---------|------------|
| **Общие** | Домен, порты, TLS, режим Multi-Node, тема, язык |

| **Telegram** | Бот для уведомлений и входа |
| **Подписка** | Конструктор страницы подписки |

| **Администратор** | Смена логина/пароля, перезапуск панели |

## Справка по разделам

На страницах **Подключения**, **Ноды**, **Клиенты** и **Хосты** в шапке есть кнопка **?** (справка) — краткое описание назначения раздела и основных действий.

## Язык и тема

- **Язык интерфейса** переключается в настройках или сохраняется в локальных предпочтениях браузера. Поддерживаются русский, английский и другие языки.
- **Тема** (светлая / тёмная) настраивается в общих настройках.

## Публичная страница подписки

Отдельный маршрут `/panel/sub/?id=<subId>` — страница для конечных пользователей без бокового меню панели. Открывается при переходе по ссылке подписки из браузера.

## API Docs

Встроенный просмотрщик REST API (`/panel/api-docs/`) — описание эндпоинтов для автоматизации и интеграций. Полная документация: `web/docs/API.md`.

## DB Inspector

Раздел **Настройки → DB Inspector** (`/panel/db-inspector/`) — просмотр таблиц PostgreSQL для отладки. Не предназначен для повседневной работы.

## Типичный рабочий процесс

```
1. Дашборд          → проверить состояние системы
2. Подключения      → создать/настроить inbound
3. Клиенты           → добавить пользователя, назначить inbound
4. Настройки → Подписка → оформить страницу подписки
5. Передать клиенту ссылку подписки
```

При multi-node:

```
1. Настройки → включить Multi-Node
2. Ноды → добавить воркеры
3. Подключения → создать inbound → назначить ноды
4. Хосты → настроить CDN/домены для подписок
5. Клиенты → создать и назначить inbound'ы
6. Настройки → Подписка → оформить страницу
```
