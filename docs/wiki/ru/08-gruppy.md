# 8. Группы

[← Клиенты](./07-klienty.md) | [Оглавление](./README.md) | [Страница подписки →](./09-stranica-podpiski.md)

## Назначение групп

**Группа** — логическое объединение клиентов для:

- фильтрации списка клиентов;
- массового применения настроек (лимиты, inbound'ы, срок, HWID);
- удобной организации при большом числе пользователей.

Один клиент может принадлежать **только одной** группе (или ни одной).

## Список групп

Страница **Группы** (`/panel/groups/`):

| Колонка | Описание |
|---------|----------|
| **Имя** | Название группы |
| **Описание** | Краткое описание |
| **Клиентов** | Количество клиентов в группе |
| **Действия** | Редактировать / Удалить |

## Создание группы

1. Нажмите **Добавить группу**.
2. Заполните:
   - **Имя группы** * (до 30 символов);
   - **Описание** (до 100 символов).
3. Нажмите **Создать**.

## Редактирование группы

Кликните **Редактировать** — откроется модальное окно с несколькими секциями. Одна кнопка **Сохранить** применяет все изменённые секции.

### Быстрые действия (панель иконок)

| Действие | Описание |
|----------|----------|
| Включить всех | Активировать всех клиентов группы |
| Отключить всех | Деактивировать всех |
| Сбросить трафик | Обнулить счётчики |
| Очистить HWID | Удалить зарегистрированные устройства |
| Удалить всех клиентов | Удалить всех клиентов группы |

### Секция: Идентификация

- Имя группы;
- Описание.

### Секция: Данные группы

- Количество клиентов;
- Дата создания / обновления (только чтение).

### Секция: Срок действия

Массово установить **дату истечения** для всех клиентов группы.

Если у клиентов разные значения — отображается подсказка **смешанные значения**.

### Секция: Лимит трафика (ГБ)

Массово установить лимит трафика.

### Секция: Назначить inbound'ы

Массово назначить подключения клиентам группы:

- **Заменить** — заменить текущий набор inbound'ов;
- **Добавить** — добавить к существующим.

### Секция: HWID

Массово включить/выключить ограничение HWID и задать лимит устройств.

### Секция: Лимит IP

Массово включить/выключить лимит одновременных IP и задать максимум.

## Назначение клиентов в группу

Три способа:

### 1. При создании / редактировании клиента

В форме клиента выберите группу в выпадающем списке **Группа**.

### 2. Массовое назначение на странице клиентов

1. **Клиенты** → **Массовые действия**.
2. Выберите клиентов чекбоксами.
3. **Назначить группу** → выберите группу.

Клиент, уже состоящий в другой группе, будет **перемещён** (не дублирован).

### 3. Снятие с группы

**Массовые действия** → **Назначить группу** → выберите «Без группы» (или используйте API `group/0/removeClients`).

## Удаление группы

При удалении группы:

- запись группы удаляется;
- у всех клиентов этой группы поле `group_id` обнуляется;
- **клиенты не удаляются**.

## Фильтрация по группе

На странице **Клиенты** используйте фильтр **Все группы** / конкретная группа для отображения только нужных клиентов.

## Примеры использования

| Сценарий | Группа | Действие |
|----------|--------|----------|
| Тариф «Базовый» | `basic` | Лимит 50 ГБ, 1 inbound |
| Тариф «Премиум» | `premium` | Безлимит, все inbound'ы |
| Тестовые аккаунты | `test` | Срок 7 дней, сброс по истечении |
| Корпоративные | `corp` | HWID = 2, IP limit = 3 |

## Ограничения

- Максимальная длина имени: **30** символов.
- Максимальная длина описания: **100** символов.
- Клиент — **одна** группа.
- На странице групп нет отдельного «добавить клиентов в группу» — используйте массовое назначение на странице клиентов или поле группы в форме клиента.
