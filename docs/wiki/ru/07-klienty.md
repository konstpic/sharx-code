# 7. Клиенты

[← Хосты](./06-hosty.md) | [Оглавление](./README.md) | [Группы →](./08-gruppy.md)

## Клиент vs администратор

| | Клиент (Client) | Администратор (Admin) |
|---|-----------------|----------------------|
| Назначение | Конечный пользователь VPN/прокси | Вход в панель управления |
| Где создаётся | **Клиенты** → Добавить клиента | При первой установке; смена в **Настройки → Администратор** |
| Таблица БД | `client_entities` | `users` |
| Количество | Много | Один (в текущей версии) |

В интерфейсе раздел называется **Клиенты** (или **Пользователи** в статистике).

## Список клиентов

Страница **Клиенты** (`/panel/clients/`):

### Сводные плитки

- **Всего пользователей** — общее количество клиентов.
- **Онлайн** — активные подключения.
- **Оффлайн** — неактивные.
- **Показано по фильтрам** — количество после применения фильтров.

### Таблица

| Колонка | Описание |
|---------|----------|
| ID | Идентификатор |
| Имя | Уникальное имя клиента (латиница, нижний регистр) |
| Комментарий | Произвольный комментарий |
| Статус | ACTIVE / DISABLED / EXPIRED / LIMITED |
| Состояние | Включён / выключен |
| Трафик ↑/↓ | Использовано / лимит |
| Срок | Дата истечения |
| Группа | Принадлежность к группе |
| Inbound'ы | Назначенные подключения |
| UUID | Идентификатор протокола |
| Sub ID | Идентификатор подписки |

Доступны поиск, фильтр по группе, сортировка по столбцам.

## Создание клиента (пошагово)

### Шаг 1. Открыть форму

**Клиенты** → **Добавить клиента**. Справа откроется боковая панель.

### Шаг 2. Заполнить обязательные поля

Минимум для рабочей подписки:

1. **Имя клиента** — латиница, нижний регистр (`ivanov`, `user001`). Уникально в рамках панели.
2. **Inbound'ы** — выберите хотя бы одно подключение. Без inbound подписка будет пустой.

### Шаг 3. Настроить лимиты (по желанию)

- **Лимит трафика (ГБ)** — например, `100` или `0` (безлимит).
- **Срок** — дата окончания или пусто (бессрочно).
- **HWID** / **Лимит IP** — см. [раздел 11](./11-hwid-i-limity.md).

### Шаг 4. Сохранить

Нажмите **Сохранить**. UUID копируется в буфер обмена. Форма переключается в режим редактирования — оттуда можно скопировать **Sub ID** и ссылку подписки.

### Блоки формы

#### Идентификация

| Поле | Обязательно | Описание |
|------|-------------|----------|
| **Имя клиента** | Да | Уникальное имя (при создании; после сохранения не меняется) |
| **Комментарий** | Нет | До 100 символов |
| **UUID** | Авто | Генерируется автоматически; копируется в буфер после создания |

#### Контакты

| Поле | Описание |
|------|----------|
| **Telegram ID** | Для уведомлений через Telegram-бота |
| **ID подписки** | Автоматически 16 символов; задаётся только при создании |

#### Срок действия

| Поле | Описание |
|------|----------|
| **Срок** | Дата и время истечения; пусто = бессрочно |

#### Трафик и сброс

| Поле | Описание |
|------|----------|
| **Лимит трафика (ГБ)** | 0 = безлимит |
| **Сброс (дни)** | Период сброса счётчика трафика |

#### Inbound'ы

Выберите одно или несколько **подключений**, к которым будет иметь доступ клиент. При двух и более inbound'ах можно задать **порядок в подписке**.

#### Группа

Выберите группу из выпадающего списка (опционально).

#### Настройки HWID

См. [HWID и лимиты](./11-hwid-i-limity.md#hwid-ограничение-устройств).

#### Лимит IP

См. [HWID и лимиты](./11-hwid-i-limity.md#лимит-одновременных-ip).

#### Объявление

Текст объявления (до 200 символов), который может отображаться в подписке клиента.

## Редактирование клиента

Кликните на строку клиента — откроется та же боковая панель в режиме редактирования.

Дополнительно отображается блок **Данные аккаунта**:

- ID подписки (только чтение);
- Дата создания / обновления;
- Последний онлайн;
- Скорости загрузки / отдачи.

**Имя клиента** после создания изменить нельзя.

## Ссылка подписки

Каждый клиент имеет уникальный **Sub ID**. Ссылка подписки формируется так:

```
https://<домен-подписки>:2096/sub/<subId>
```

или с путём из настроек (`XUI_SUB_PATH`).

При открытии в браузере пользователь перенаправляется на **публичную страницу подписки**:

```
https://<домен-панели>/panel/sub/?id=<subId>
```

Клиентские приложения (Happ, v2rayNG, Clash и др.) получают конфигурацию в формате, зависящем от User-Agent.

## Состояния клиента

| Статус | Условие |
|--------|---------|
| **ACTIVE** | Включён, трафик в пределах лимита, срок не истёк |
| **DISABLED** | Отключён администратором |
| **EXPIRED** | Истёк срок действия |
| **LIMITED** | Исчерпан лимит трафика |

## Массовые действия

Нажмите **Массовые действия** → выберите клиентов чекбоксами:

| Действие | Описание |
|----------|----------|
| **Назначить группу** | Переместить в выбранную группу |
| **Сбросить трафик** | Обнулить счётчик |
| **Очистить HWID** | Удалить зарегистрированные устройства |
| **Удалить** | Удалить выбранных клиентов |

> Внимательно подтверждайте массовые операции — они применяются ко всем выбранным аккаунтам.

## Управление HWID

В строке клиента или в форме редактирования:

- **Устройства: N / M** — зарегистрировано / лимит.
- Кнопка **Зарегистрированные устройства (HWID)** — модальное окно со списком устройств (OS, модель, HWID, дата регистрации).
- **Очистить HWID** — сбросить все зарегистрированные устройства.

Глобальные действия (в меню страницы):

- **Очистить все HWID** — для всех клиентов;
- **Установить лимит HWID** — массово задать лимит устройств.

## Статистика клиентов

Раздел **Клиенты → Статистика** (`/panel/clients/statistics/`) — графики и таблицы трафика по клиентам.

## Рекомендации

1. **Имя клиента** — используйте понятные имена (`user123`, `ivanov`).
2. **Назначайте inbound'ы** сразу при создании — без них подписка будет пустой.
3. **Sub ID** — не меняйте без необходимости; клиентские приложения кэшируют ссылку.
4. **Лимиты** — согласуйте трафик, срок и HWID с тарифным планом.
5. **Группы** — используйте для организации при большом числе клиентов.

## Пример: клиент с одним VLESS inbound

| Поле | Значение |
|------|----------|
| Имя | `testuser` |
| Inbound | `VLESS-REALITY-443` |
| Лимит трафика | `50` ГБ |
| Срок | +30 дней |
| HWID | Выкл |

После сохранения клиент получает подписку вида:

```
https://sub.example.com:2096/sub/abc123def4567890
```

В приложении Happ / v2rayNG — **Добавить подписку** → вставить URL.
