# 11. HWID и лимиты

[← Маршрутизация](./10-marshrutizaciya.md) | [Оглавление](./README.md) | [Настройки →](./12-nastrojki.md)

Все лимиты в SharX применяются к **клиентам** (конечным пользователям), а не к администраторам панели.

## Обзор типов ограничений

| Тип | Уровень | Описание |
|-----|---------|----------|
| **Лимит трафика** | Клиент | Максимальный объём данных (ГБ) |
| **Срок действия** | Клиент | Дата истечения аккаунта |
| **HWID** | Клиент | Максимум зарегистрированных устройств |
| **Лимит IP** | Клиент | Максимум одновременных уникальных IP |
| **Лимит трафика ноды** | Нода | Суммарный трафик через воркер |
| **Сброс трафика** | Клиент / Inbound | Периодический обнуление счётчика |

---

## Лимит трафика

### На уровне клиента

| Поле | Описание |
|------|----------|
| **Лимит трафика (ГБ)** | 0 = безлимит |
| **Сброс (дни)** | Период автоматического сброса счётчика |

При превышении лимита статус клиента меняется на **LIMITED**. В подписке может отображаться пользовательское примечание (если настроено).

**Сброс вручную:** меню клиента → **Сбросить трафик**; или массово через группу / массовые действия.

### На уровне inbound

При создании подключения: **Сброс трафика** — never / hourly / daily / weekly / monthly. Обнуляет счётчик inbound'а (не клиента).

### На уровне ноды

Поле **Лимит трафика (ГБ)** при добавлении ноды. 0 = без ограничения.

---

## Срок действия

| Поле | Описание |
|------|----------|
| **Срок** | Дата и время истечения |

- Пустое значение = **бессрочно**.
- При истечении статус → **EXPIRED**.
- Массовая установка срока: через **группу** → секция «Срок действия».

## HWID (ограничение устройств)

> **Бета-функция.** Работает только с клиентами **Happ** и **v2rayTun**. Другие приложения могут не поддерживать регистрацию HWID.

### Назначение

**HWID (Hardware ID)** — уникальный идентификатор устройства. Ограничение по HWID защищает от утечки подписки: даже если ссылка станет известна третьим лицам, подключиться смогут только зарегистрированные устройства.

### Настройка на клиенте

В форме клиента, секция **Настройки HWID**:

| Поле | Описание |
|------|----------|
| **Включить ограничение по HWID** | Активировать проверку |
| **Максимум устройств (HWID)** | 0 = безлимит |

### Глобальный режим HWID

**Настройки → Безопасность → Режим HWID**:

| Режим | Описание |
|-------|----------|
| **Выкл** | HWID не проверяется глобально |
| **Заголовок клиента (x-hwid)** | Регистрация по заголовку `x-hwid` / `X-HWID` (рекомендуется) |
| **Legacy fingerprint** | Устаревший метод (deprecated) |

### Как работает регистрация

1. Клиентское приложение (Happ / v2rayTun) при запросе подписки отправляет заголовки:
   - `x-hwid` / `X-HWID` — идентификатор устройства (обязательный);
   - `x-device-os` — операционная система;
   - `x-device-model` — модель устройства;
   - `x-ver-os` — версия ОС.

2. Панель регистрирует устройство в таблице `client_hw_ids`.

3. Если количество устройств превышает `maxHwid` → подписка возвращает **403 Forbidden** или пользовательское примечание `HWIDMaxDevicesExceeded`.

4. Если HWID включён, но заголовок не отправлен → `HWIDNotSupported`.

### Просмотр устройств

В форме клиента или в строке списка: **Зарегистрированные устройства (HWID)** — модальное окно со списком:

- HWID;
- ОС и модель;
- Дата регистрации.

Отображение: **Устройства: N / M** (зарегистрировано / лимит).

### Управление HWID

| Действие | Где |
|----------|-----|
| **Очистить HWID** | Форма клиента / массовые действия |
| **Очистить все HWID** | Меню страницы клиентов |
| **Установить лимит HWID** | Массово для всех клиентов |
| **Очистить HWID** | Группа → быстрые действия |

### Telemt (MTProto)

Для клиентов Telemt лимит HWID может транслироваться в `MaxUniqueIPs` в конфигурации Telemt sidecar.

## Лимит одновременных IP

Отдельный механизм от HWID. Ограничивает количество **одновременных уникальных IP-адресов**, с которых клиент подключён.

### Настройка на клиенте

Секция **Лимит IP**:

| Поле | Описание |
|------|----------|
| **Ограничить одновременные IP** | Включить проверку |
| **Макс. уникальных IP** | Минимум 1 при включении |

### Глобальные настройки

**Настройки → Безопасность**:

| Параметр | Описание |
|----------|----------|
| **Включить контроль лимита IP** | Фоновая задача проверки |
| **Интервал проверки (сек)** | 5–600 секунд |
| **Длительность бана IP (сек)** | 0 = навсегда до ручной разблокировки |
| **Режим применения** | Drop / Block / Drop + Block |
| **Политика лишних IP** | Отключать новые / Отключать старые |

### Режимы применения

| Режим | Действие |
|-------|----------|
| **Только разрыв соединений (Drop)** | Разрывает активные сессии с «лишних» IP |
| **Блокировка IP в подписке (Block)** | Запрещает подписку и маршрутизацию для IP |
| **Разрыв и блокировка** | Оба действия |

### Политика лишних IP

| Политика | Описание |
|----------|----------|
| **Отключать новые IP** | При превышении лимита блокируются последние подключившиеся |
| **Отключать старые IP** | Блокируются первые подключившиеся |

### Как работает

1. Фоновая задача `CheckClientIPLimitJob` периодически проверяет онлайн-сессии.
2. При превышении `maxIPs` применяется выбранный режим.
3. При режиме Block панель hot-push'ит правила маршрутизации на ноды для блокировки IP.

## Состояния клиента при ограничениях

| Статус | Причина | Поведение подписки |
|--------|---------|-------------------|
| **ACTIVE** | Всё в норме | Полная подписка |
| **DISABLED** | Отключён админом | Заглушка или пустая (зависит от настроек) |
| **EXPIRED** | Истёк срок | Пользовательское примечание |
| **LIMITED** | Исчерпан трафик | Пользовательское примечание |
| HWID exceeded | Слишком много устройств | 403 или `HWIDMaxDevicesExceeded` |
| IP exceeded | Слишком много IP | Drop/Block по настройкам |

Переключатель **Показывать пользовательские примечания** (Настройки → Подписка) определяет, показывать ли заглушку или реальные серверы при ограничении.

## Массовое управление лимитами

### Через группы

Редактирование группы → секции: Срок, Трафик, HWID, IP limit.

### Через массовые действия (Клиенты)

- Сбросить трафик;
- Очистить HWID;
- Установить лимит HWID (глобально).

### Через API

```
POST /panel/client/setHwidLimitAll
POST /panel/client/clearAllHwids
POST /panel/client/clearHwid/:id
POST /panel/group/:id/bulk/setTrafficLimit
POST /panel/group/:id/bulk/setExpiry
```

## Сравнение HWID и лимита IP

| | HWID | Лимит IP |
|---|------|----------|
| **Что ограничивает** | Количество устройств | Количество одновременных IP |
| **Когда проверяется** | При запросе подписки | Фоновая задача (периодически) |
| **Клиенты** | Happ, v2rayTun | Все |
| **Защита от утечки** | Да (устройство привязано) | Частично (IP могут меняться) |
| **Статус** | Бета | Стабильный |

Рекомендуется использовать **оба** механизма для максимальной защиты.

---

## Рекомендации

1. **HWID** — включайте для клиентов с риском утечки подписки; предупреждайте, что нужен Happ или v2rayTun.
2. **Лимит IP** — для защиты от раздачи аккаунта; начните с 2–3 IP.
3. **Трафик + срок** — базовые лимиты для любого тарифа.
4. **Custom remarks** — напишите понятные тексты для каждого состояния ограничения.
5. При жалобах «не работает» — проверьте статус, HWID-устройства и заблокированные IP.
