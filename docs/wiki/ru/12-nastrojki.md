# 12. Настройки панели

[← HWID и лимиты](./11-hwid-i-limity.md) | [Оглавление](./README.md)

Раздел **Настройки** (`/panel/settings/`) содержит семь вкладок.

---

## Общие

`/panel/settings/general/`

| Параметр | Описание |
|----------|----------|
| **Доменное имя** | Публичный домен панели |
| **Порт** | Порт веб-интерфейса (синхронизируется с `XUI_WEB_PORT`) |
| **Путь к сертификату / ключу** | TLS для панели |
| **Домен подписки** | Домен для ссылок подписки |
| **Порт подписки** | Порт сервиса подписок (`XUI_SUB_PORT`) |
| **Путь подписки** | URI-путь (`XUI_SUB_PATH`) |
| **Режим Multi-Node** | Включить распределённую архитектуру |
| **Язык панели** | Язык интерфейса |
| **Тема** | Светлая / тёмная |
| **Часовой пояс** | Для отображения дат |
| **Версия Xray** | Управление версией ядра |
| **Обновление панели** | Проверка и установка обновлений |

### Режим Multi-Node

При включении:

- Xray Core **не работает** локально на панели;
- конфигурации **отправляются** на рабочие ноды;
- inbound'ы **необходимо назначить** на ноды;
- подписки используют **адреса нод**.

## Безопасность

`/panel/settings/security/`

| Параметр | Описание |
|----------|----------|
| **Двухфакторная аутентификация (2FA)** | TOTP (Google Authenticator и аналоги) |
| **API-токены** | Токены для доступа к REST API без cookie-сессии |
| **Режим HWID** | Выкл / x-hwid / legacy fingerprint |
| **Контроль лимита IP** | Глобальное включение проверки IP |
| **Интервал проверки IP** | 5–600 секунд |
| **Длительность бана IP** | 0 = навсегда |
| **Режим применения IP** | Drop / Block / Drop + Block |
| **Политика лишних IP** | Новые / Старые |
| **Fail2Ban** | Защита от брутфорса (через `XUI_ENABLE_FAIL2BAN`) |

### Настройка 2FA

1. Включите 2FA.
2. Отсканируйте QR-код в приложении-аутентификаторе.
3. Введите код подтверждения.
4. Сохраните резервные коды.

### API-токены

Создайте токен с описанием и сроком действия. Используйте в заголовке:

```
Authorization: Bearer <token>
```

## Подписка

`/panel/settings/subscription/`

Визуальный **конструктор страницы подписки**. Подробнее: [Страница подписки](./09-stranica-podpiski.md).

Вкладки конструктора:

- Брендинг
- Блоки
- Правила ответа
- Пользовательские примечания
- Маршрутизация клиента
- JSON-шаблоны
- Raw JSON

---

## LDAP

`/panel/settings/ldap/`

Внешняя аутентификация администратора панели через LDAP / Active Directory.

| Параметр | Описание |
|----------|----------|
| **Включить LDAP** | Активировать |
| **Адрес сервера** | host:port |
| **Base DN** | Базовый DN для поиска |
| **Bind DN / Password** | Учётные данные для подключения |
| **Фильтр пользователя** | LDAP-фильтр |
| **Атрибут имени** | Поле username |

При включённом LDAP локальный пароль используется как fallback.

---

## Grafana

`/panel/settings/grafana/`

Интеграция с внешним стеком наблюдаемости (Grafana, Loki, VictoriaMetrics **не входят** в compose по умолчанию).

| Параметр | Описание |
|----------|----------|
| **URL Loki** | Отправка логов |
| **URL VictoriaMetrics** | Отправка метрик |
| **Скачать дашборд** | JSON-дашборд Grafana для импорта |

Встроенные метрики Prometheus: `{basePath}panel/metrics` — ограничьте доступ на уровне сети или reverse proxy.

## Администратор

`/panel/settings/admin/`

### Учётные данные администратора

| Поле | Описание |
|------|----------|
| **Текущее имя пользователя** | Для подтверждения |
| **Текущий пароль** | Для подтверждения |
| **Новое имя пользователя** | Новый логин |
| **Новый пароль** | Новый пароль |

> В текущей версии поддерживается **один** администратор панели. Создание дополнительных админов через UI недоступно.

Альтернативные способы смены учётных данных:

- CLI-флаги при запуске: `-username`, `-password`;
- Первый запуск с пустой БД: `admin` / `admin`.

### Перезапуск панели

Кнопка **Перезапустить панель** — перезапуск процесса без пересоздания контейнера.

## DB Inspector

`/panel/db-inspector/`

Просмотр таблиц PostgreSQL в режиме только чтения (с осторожностью). Таблицы:

- `users` — администратор;
- `client_entities` — клиенты;
- `client_groups` — группы;
- `inbounds` — подключения;
- `nodes` — ноды;
- и другие.

Не предназначен для повседневной работы.

## Переменные окружения vs веб-настройки

| Параметр | Где задаётся |
|----------|--------------|
| Порты панели и подписки | Только env (`XUI_WEB_PORT`, `XUI_SUB_PORT`) |
| Пути SSL | Env или веб-настройки |
| Пароль PostgreSQL | Только env |
| Multi-Node, 2FA, Telegram | Веб-настройки |
| Домен, тема, язык | Веб-настройки |

Полный справочник: `ENV_VARIABLES.md`.
