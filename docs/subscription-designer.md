# Визуальный конструктор страницы подписки

Документ для версии 2.1.0. Конструктор (в интерфейсе — «Конструктор страницы подписки», далее «дизайнер») собирает публичную страницу, которую клиент открывает по ссылке подписки (`/panel/sub/?id=<subId>`). Страница строится из элементов: их можно двигать, вкладывать друг в друга, показывать по условию, оживлять анимацией и подставлять в них данные конкретного клиента.

> **Важно: у дизайнера нет мобильной адаптации.** Редактор рассчитан только на компьютер (нужен широкий экран компьютера: две боковые панели фиксированной ширины 300 и 320 px плюс холст). С телефона или планшета редактировать страницу нельзя. Страница, которую он создаёт, при этом **адаптивна**: её можно посмотреть в рамке «Телефон» (390 px) прямо на холсте и настроить отдельный вид для узких экранов. Подробнее — в разделе [Ограничения](#ограничения-и-известные-особенности).

## Быстрый старт за 5 шагов

1. **Откройте дизайнер.** Настройки → «Подписка» → карточка «Визуальный конструктор» → **«Открыть конструктор»**. При первом входе предложат пройти [тур](#обучающий-тур); можно выбрать «Быстрый старт (2 мин)».
2. **Возьмите шаблон.** Кнопка **«Шаблоны»** на верхней панели → выберите один из 21 готового шаблона (например «Вау-шоукейс» или «Минимал Дзен»). Шаблон заменит текущий макет и переключит палитру; это можно отменить (⌘/Ctrl+Z).
3. **Добавьте и поправьте элементы.** Вкладка **«Добавить»**: клик по элементу добавляет его, перетаскивание кладёт туда, куда вы отпустили. Выберите элемент на холсте и настройте его в **инспекторе** справа.
4. **Проверьте на реальном клиенте и на телефоне.** На верхней панели вставьте `subId` клиента в поле «subId клиента → реальные данные» и нажмите кнопку-глаз. Переключайте рамки «Телефон / Планшет / Десктоп».
5. **Опубликуйте.** Включите флажок **«Показывать на странице»** (в англоязычном интерфейсе — «Use on page») и нажмите **«Сохранить»**. Пока флажок выключен или вы не сохранили, клиенты видят прежнюю страницу.

## Как открыть и опубликовать

**Открыть.** Настройки → «Подписка» (`/panel/settings/subscription/`) → карточка «Визуальный конструктор» → «Открыть конструктор». Если макет включён, на карточке стоит метка «используется». Дизайнер открывается поверх страницы на весь экран; прокрутка страницы под ним блокируется.

**Верхняя панель** (слева направо): закрыть; отменить и повторить; сетка и привязка; рамка устройства (Телефон, Планшет, Десктоп) с шириной в px; масштаб; язык предпросмотра; поле `subId` клиента; справка «?»; «Тур»; «Шаблоны»; «Сохранить страницу как шаблон» (закладка); «CSS страницы»; JSON макета; флажок **«Показывать на странице»**; **«Сохранить»**.

**Как работает публикация.**

- Макет — это поле `layout` конфига страницы. Флажок «Показывать на странице» — это `layout.enabled`.
- Флажок выключен — клиенты видят классические блоки, макет при этом **сохраняется** и не теряется.
- Кнопка «Сохранить» записывает **весь конфиг страницы** сразу: макет, палитру, фон, режим темы. Рядом с надписью появляется точка «•», пока есть несохранённые изменения.
- Закрытие с несохранёнными изменениями требует подтверждения.
- Правки палитры и цветов на вкладке «Стили» относятся к конфигу, а не к макету: они тоже применяются только после «Сохранить».
- Сохранение в хранилище (элементы и шаблоны, см. ниже) — отдельный механизм, он не требует кнопки «Сохранить».

**Страница по умолчанию.** Если конфиг никогда не менялся (ни блоки, ни макет не редактировались), публичная страница показывает готовый макет «Вау-шоукейс». Как только вы отредактируете блоки или сохраните макет (даже выключенный), классическая страница остаётся как есть.

## Рецепты

### Трафик и дни рядом

1. Добавьте два элемента, например из каталога «Полоса трафика» и «Дней осталось». Они встанут друг под другом.
2. **Способ А (перетаскиванием).** Возьмите один элемент и бросьте на **левый или правый край** другого. Появится вертикальная линия, и элементы встанут в один ряд.
3. **Способ Б (через меню).** Выделите оба элемента (Shift+клик), правый клик → **«Расположить рядом»** или ⌘/Ctrl+Shift+R. Получится горизонтальный фрейм.
4. Чтобы вернуть обратно: выберите этот фрейм → «Разбить строку» (то же сочетание ⌘/Ctrl+Shift+R).
5. Проверьте рамку «Телефон». Ряд из шаблона «Ряд» на узком экране сам становится колонкой; для своего фрейма включите в инспекторе «Перенос» или задайте отдельное поведение в режиме «Правка мобильного вида».

### Выключить фон

1. Вкладка **«Стили»** → блок «Фон» → выберите **«Однотонный»**.
2. Анимированная атмосфера палитры и её декор (бантики, искры, сетка) исчезнут. Флажок «Декор палитры» при однотонном фоне недоступен.
3. Хотите оставить анимацию, но без декора — выберите «Анимированный» и снимите флажок «Декор палитры (бантики, искры, сетка)».
4. Нажмите «Сохранить». Значения пишутся в `branding.background` (`plain` / `animated`) и `branding.decorations`.

### Перевести страницу

1. Убедитесь, что нужные языки включены: Настройки → «Подписка» → вкладка «Брендинг» → языки (`locales`). Переключатель языка на странице показывается при двух и более языках.
2. В дизайнере откройте вкладку **«Переменные»** → раздел **«Переводы»**. Найдите нужный текст поиском.
3. Раскройте текст: для каждого языка появится поле. Впишите перевод. Индикатор языка станет зелёным (✓), если непереведённых текстов нет, и жёлтым («−N»), если чего-то не хватает.
4. Свои тексты в элементах: добавьте ключ («Добавить текст», например `welcome`), заполните языки и вставьте в любое текстовое поле `{{ tr.welcome }}` (клик по подсказке под полем вставляет её).
5. Проверьте: выпадающий список языка на верхней панели переключает предпросмотр.

Готовые элементы каталога уже содержат тексты на английском и русском внутри макета; ещё 11 языков подгружаются из встроенных словарей (см. [Переводы](#переводы)).

### Сохранить свой элемент в хранилище

1. Выделите элемент на холсте (можно несколько с общим родителем).
2. Нажмите кнопку-закладку в инспекторе, либо ⌘/Ctrl+Shift+S, либо правый клик → «Сохранить в хранилище…».
3. Задайте название, описание и теги (через запятую) и подтвердите. Внизу окна показано, что именно сохранится.
4. Элемент появится на вкладке «Добавить» в категории **«Моё хранилище»**. Он доступен всем администраторам панели из любого браузера.
5. Изменили элемент на холсте? Выделите его и в хранилище выберите «Обновить из выделения».

### Сделать элемент анимированным

1. Выберите элемент. В инспекторе откройте раздел **«Анимация»**.
2. В поле «Эффект» выберите готовый, например «Плавное появление» или «Пульсация». Предпросмотр проигрывается сразу; кнопка «Повторить» запускает заново.
3. Выберите «Запуск»: при загрузке, при появлении на экране, при наведении, по клику, при фокусе или по прокрутке.
4. Настройте длительность, задержку и кривую. Для группы элементов на родительском фрейме задайте «Каскад».
5. Не хотите настраивать вручную? Во вкладке «Добавить» включите фильтр **«Анимированные»** и возьмите готовый элемент.

## Модель макета

Макет — дерево узлов, хранится плоско: словарь `nodes` по id и списки `children`. Корень — «Страница».

### Фреймы

Фрейм — контейнер. Режим задаётся в инспекторе, раздел «Раскладка»:

| Режим | Что делает |
|---|---|
| **Стек** | Дочерние идут по порядку: «Вертикально» или «Горизонтально» (`dir`), «Перенос», «Промежуток» (`gap`), выравнивание по «Главной оси» (Начало, Центр, Конец, Между, Вокруг, Равномерно) и по «Поперечной оси» (Растянуть, Начало, Центр, Конец, По базовой линии). |
| **Сетка** | «Колонки» (число) или «Мин. колонка» (автоколонки, перекрывает число колонок), «Промежуток». |
| **Свободно** | Дочерние позиционируются по X / Y, слою и углу поворота. У такого фрейма нужна **фиксированная высота**. |

Размеры элемента: «Авто», «Заполнить» или фиксированное значение (px, %, rem). Дополнительно: мин/макс размеры, «Рост» (доля свободного места в стеке), «Пропорции», внешний отступ, выравнивание самого элемента.

### Типы элементов

| Тип (`type`) | Название в интерфейсе | Назначение |
|---|---|---|
| `frame` | Фрейм | Контейнер: стек, сетка или свободный |
| `text` | Текст | Текст с переменными; тег: абзац, в строке, h1–h4 |
| `button` | Кнопка | Действие: «Открыть ссылку», «Копировать текст», «Показать QR-код», «Добавить в приложение», «Переключить состояние»; стили «Заливка», «Контур», «Прозрачная» |
| `image` | Картинка | URL, альтернативный текст, вписывание (Заполнить, Вместить, Растянуть) |
| `badge` | Бейдж | Метка статуса, тон: Нейтральный, Акцент, Успех, Предупреждение, Опасность |
| `progress` | Прогресс | Полоса: значение, максимум, подпись, цвет |
| `icon` | Иконка | Значок из набора |
| `qr` | QR-код | QR из любого текста (в том числе с переменными) |
| `divider` | Разделитель | Линия |
| `spacer` | Отступ | Пустое место |
| `repeat` | Повтор | Копия дочерних элементов на каждое устройство, ссылку, приложение, Telegram-прокси или свой список; «Лимит», «Текст, если пусто» |
| `html` | Свой код | HTML / CSS / (по флажку) JS с переменными; см. [Свой код](#свой-код-и-параметры) |
| `header` | Шапка | Брендовая полоса: логотип, заголовок, подзаголовок, кнопки «Получить ссылку» и поддержки; данные берутся с вкладки «Брендинг» |
| `locale-switch` | Выбор языка | Переключатель языка посетителя; виден при двух и более языках в конфиге |
| `scene` | Сцена | Анимированное объяснение, см. [Сцены](#сцены) |
| `apps` | Кнопки приложений | Кнопки «Добавить в приложение» со своим списком или из конфига, см. ниже |
| `block` | Классический блок | Готовый блок прежней страницы (информация о подписке, метрики, инструкция, ссылки, «Добавить в приложение», поддержка, свой HTML) |

**Кнопки приложений (`apps`).** Источник: «Свой список» (выбираете приложения вручную, порядок стрелками «Выше»/«Ниже», для каждого можно поменять название, URL иконки, deep link и включить «Зашифрованная ссылка (E2E)») или «Из конфига» (берёт приложения классического блока «Добавить в приложение»). Отображение: «Кнопки», «Плитки», «Список»; колонки; иконки; метка E2E. Кнопка «Заполнить из блока «Добавить в приложение»» копирует список из конфига. Ссылки строятся для каждого посетителя из его подписки.

### Заготовки

Раздел «Готовые заготовки» на вкладке «Добавить»: «Карточка», «Плитка-показатель», «Приветствие», «Список устройств», «Кнопки приложений», «Список ссылок», «Кнопка поддержки», «Ряд» (горизонтальный фрейм, на телефоне колонка). Раздел «Классические блоки» вставляет блоки прежней страницы как обычные редактируемые элементы.

### Слои

Вкладка **«Слои»** — дерево макета: выбор, перетаскивание (порядок и вложенность), скрыть (глаз), заблокировать (замок). Порядок отрисовки: более поздние элементы рисуются поверх; в инспекторе, раздел «Слои», есть «На передний план», «Вперёд», «Назад», «На задний план» и `z-index` в разделе «Размер».

## Холст

- **Устройства.** Рамки «Телефон» (390 px), «Планшет» (768 px), «Десктоп» (1200 px). По умолчанию открывается «Телефон». При переходе на рамку «Телефон» режим правки возвращается к «для всех экранов».
- **Масштаб.** Кнопки «−» и «+» (25–200 %), клик по проценту — 100 %, «Вписать в экран» (по умолчанию включено; масштаб не больше 100 % и не меньше 30 %).
- **Выбор.** Клик выбирает элемент; Shift+клик добавляет или убирает из выделения; клик по пустому месту — снять выделение; Esc снимает выделение, повторное Esc закрывает дизайнер.
- **Перетаскивание.** Возьмите выбранный элемент и перенесите: синяя линия показывает, куда он встанет. Новые элементы тоже перетаскиваются с вкладки «Добавить». Во фрейме «Свободно» элемент двигается на месте с привязкой.
- **Рядом друг с другом.** Бросьте элемент на левый или правый край другого элемента в стеке: получится ряд (новый или в уже существующий). Работает для одного перетаскиваемого элемента.
- **Ручки размера** у выбранного элемента меняют ширину и высоту (в мобильном режиме правки — только мобильный вид).
- **Правка текста на месте.** Двойной клик по тексту. Enter (без Shift) или Esc завершают ввод.
- **Контекстное меню** (правый клик): «Дублировать», «Копировать», «Вставить внутрь», «Сохранить в хранилище…», «Сгруппировать», **«Расположить рядом»**, **«Разбить строку»**, «Разгруппировать», «Сдвинуть раньше», «Сдвинуть позже», «Удалить».
- **Сетка и привязка** (кнопка в верхней панели или клавиша **G**): «Показать сетку», «Привязка к сетке», «Шаг, px» (4, 8, 10, 16, 24, 32 или свой от 2 до 100; по умолчанию 8, сетка по умолчанию выключена). При перетаскивании и изменении размера элементы прилипают к сетке; **Alt** временно отключает привязку. Стрелки сдвигают выбранный элемент свободного фрейма на один шаг, Shift+стрелка — на десять; без привязки шаг 1 / 10 px. Во фрейме «Свободно» работают также направляющие (розовые линии) по краям и центрам соседних элементов.
- Настройки сетки запоминаются в браузере.

**Предпросмотр на данных.** По умолчанию показываются тестовые данные. Введите `subId` клиента и нажмите Enter или кнопку-глаз: дизайнер загрузит публичный ответ этого клиента (`GET /panel/api/public/subscription?id=…`), надпись «Данные реального клиента» подтверждает загрузку. Пустое поле возвращает тестовые данные. «Язык предпросмотра» переключает язык (`en`, `ru` и языки из конфига).

## Инспектор

Панель справа. Если ничего не выбрано, показываются настройки страницы: «Использовать этот макет на публичной странице», «CSS страницы» (только внутри страницы, ограничивайте селектором `.sublyt`; переменные `{{ }}` в нём не подставляются) и краткая справка. При множественном выборе доступны «Сгруппировать во фрейм», «Дублировать», «Удалить».

В шапке инспектора: `id` элемента (нужен для действий «Прокрутить к элементу» и «Показать / скрыть элемент»), название, скрыть (глаз), заблокировать (замок), «Сохранить в хранилище» (закладка), дублировать, удалить и переключатель режима правки.

### Правка мобильного вида

Переключатель справа в шапке инспектора: «Правка для всех экранов» (монитор) и «Правка мобильного вида (узкие экраны)» (смартфон). В мобильном режиме все изменения записываются только в переопределения `mobile` элемента и действуют, когда ширина контейнера страницы не больше **640 px**. Кнопка «Сбросить мобильные переопределения» убирает их. В разделе «Видимость» есть «Скрыть на мобильных» и «Скрыть на десктопе». Тур: «Вид на телефоне».

## Анимация

Раздел «Анимация» есть у любого элемента.

**Эффекты (`preset`):** «Плавное появление», «Выезд снизу», «Выезд сверху», «Выезд справа», «Выезд слева», «Увеличение», «Переворот», «Проявление из размытия», «Подпрыгивание», «Пульсация», «Парение», «Тряска», «Вращение», «Свечение», «Блик», «Печатная машинка», «Свои ключевые кадры» и «Нет». Эффекты появления играют один раз, остальные повторяются по кругу.

**Запуск (`trigger`):**

| Значение | Когда |
|---|---|
| «При загрузке» | Сразу |
| «При появлении» | Когда элемент попал в область видимости; флажок «Повторять при каждом появлении на экране» включает повтор |
| «При наведении» | Под курсором |
| «По клику» | По клику |
| «При фокусе» | Когда фокус внутри элемента |
| «По прокрутке» | Привязка к прокрутке, где браузер поддерживает `animation-timeline`; иначе — как «При появлении» |

**Параметры:** «Длительность» и «Задержка» (мс), «Кривая» (`ease`, `linear`, `ease-in`, `ease-out`, `ease-in-out`, `spring`, либо своя `cubic-bezier(a, b, c, d)` или `steps(n)`), «Направление» (Обычное, Обратное, Чередование, Чередование обратное), «Повторы» / «По кругу», «Сохранять» (Ничего, Конечное состояние, Начальное состояние, Оба), «Расстояние» и «Сила» (для выезда, парения, подпрыгивания, тряски), «Каскад» (задержка между дочерними элементами фрейма: они проигрывают эффект друг за другом).

**Свои ключевые кадры:** поле принимает тело `@keyframes`, например `from{opacity:0}to{opacity:1}`. Принимаются парные скобки, без `@`-правил, `url()`, обратных слэшей и разметки, до 2000 символов; иначе показывается «Не принято…».

**Уменьшение анимации.** Посетители, включившие в системе «уменьшение анимации» (`prefers-reduced-motion`), эффект не увидят: корень страницы отключает все анимации и переходы, а встроенные анимированные элементы каталога содержат собственное правило `prefers-reduced-motion`. Сцены при этом показывают последний шаг без цикла. В редакторе эффект играет, но ставится на паузу под курсором, чтобы элемент можно было выбрать.

## Данные и поведение

Раздел «Данные и поведение» в инспекторе.

### Стиль по условию (состояния)

Список правил: «Когда» — выражение, дальше набор изменений стиля. Быстрые поля: «Текст» (цвет), «Прозрачность», «Поворот» (масштаб), плюс «Любые свойства стиля (JSON)». Правила с истинным выражением накладываются на стиль по порядку, побеждает последнее. Ошибочное или пустое выражение никогда не срабатывает (в отличие от «Показывать, только если»). Пример: `user.percentUsed > 80` — красная заливка. Индикатор показывает, сколько правил подходит на данных предпросмотра.

### Обновление

«Обновление» — перерисовывать элемент каждые N секунд (от 1 до 3600, 0 = выключено). Нужно для значений, зависящих от времени: `{{ now | ago }}`, обратный отсчёт.

### По клику (`onClick`)

| Действие | Что делает | Поле «Значение» |
|---|---|---|
| «Ничего» | — | — |
| «Открыть ссылку» | Переход по URL | URL (и «Открывать в новой вкладке») |
| «Копировать текст» | В буфер обмена | Текст |
| «Прокрутить к элементу» | Плавная прокрутка (без плавности при уменьшении анимации) | `id` элемента |
| «Переключить состояние» | Меняет `state.<ключ>` на противоположное | Ключ состояния |
| «Задать состояние» | Записывает значение в `state.<ключ>` | Ключ и «Значение»: пусто — переключить, `true` / `false` или любой текст |
| «Показать / скрыть элемент» | Первый клик скрывает элемент с этим `id`, второй показывает | `id` элемента |

Ключ состояния: буква или `_`, далее буквы, цифры, `_`, `:`, `-`, до 61 символа.

**`state.<ключ>`** — состояние страницы на стороне посетителя. Используйте `{{ state.<ключ> }}` в текстах и `state.<ключ>` в «Показывать, только если» любого элемента или в условии правила «Стиль по условию». Состояние живёт до перезагрузки страницы и нигде не сохраняется. У кнопок собственное поле действия (раздел «Содержимое»): выберите там «Переключить состояние».

Пример «раскрывающийся блок»: кнопке — действие «Переключить состояние», ключ `more`; блоку с деталями — «Показывать, только если» `state.more`.

## Свой код и параметры

Элемент «Свой код» (`html`): поля HTML, CSS и, по флажку, JS. Переменные `{{ }}` подставляются в HTML (значения экранируются, поэтому данные клиента не могут внедрить разметку).

| Режим | Как работает |
|---|---|
| Без скриптов (по умолчанию) | HTML очищается встроенным разбором браузера и рисуется в **shadow DOM**: шрифты и цвета страницы наследуются, стили наружу и внутрь не «протекают» |
| «Разрешить JavaScript (выполняется в песочнице)» | Всё выполняется в изолированном `iframe`: `sandbox="allow-scripts allow-popups allow-popups-to-escape-sandbox"`, без `allow-same-origin`. Скрипт **не может** трогать страницу, сессию панели и родительский документ. Данные лежат в `window.sub` (`window.sub.user.username`, `window.sub.devices`, …). «Высота фрейма»: авто (следит за содержимым, 20–4000 px) или фиксированная |

### Параметры (`{{ p.key }}` и `--p-key`)

Раздел «Параметры» превращает код в настраиваемый виджет: администратор меняет ползунки и цвета, не трогая HTML.

- Кнопка «Изменить параметры…» открывает редактор: «Добавить параметр», «Ключ», «Название», «Группа», «По умолчанию», «Варианты» (для выбора).
- Типы: число, ползунок (`range`), цвет, выбор, переключатель, текст, шрифт. Для чисел и ползунков — мин, макс, шаг, единица.
- Ключ: латинская буква, затем буквы, цифры и `_`, до 32 символов; уникальный. До 60 параметров на элемент.
- Каждый параметр доступен в HTML как **`{{ p.key }}`** и в CSS как **`var(--p-key)`** (в режиме с JS — как custom property на `:root` внутри iframe). Текстовые параметры сами могут содержать шаблоны (`{{ user.username }}`, `{{ tr.key }}`).
- Значения хранятся в `values`; «Сбросить значения» возвращает значения по умолчанию.
- Встроенные анимированные элементы каталога уже содержат стандартный набор: «Длительность», «Задержка», «Кривая», «Направление», «Повторы», «Запуск», «Акцентный цвет», «Второй цвет», «Размер» (группы «Анимация», «Цвета», «Вид»). Ключи: `dur`, `delay`, `easing`, `dir`, `iter`, `trigger`, `accent`, `second`, `size`.

Пример: параметр `speed` типа «ползунок» (1–10) и CSS `.dot{animation-duration:calc(10s / var(--p-speed))}`; параметр `title` типа «текст» и HTML `<h3>{{ p.title }}</h3>`.

## Сцены

Сцена (`scene`) — небольшая анимированная схема-объяснение: участники (иконки), связи между ними и последовательность шагов с подписью. Создаётся элементом «Сцена» (базовые элементы) или готовыми сценами из каталога.

**Устройство.** `actors` — участники (`id`, подпись, иконка, позиция x/y в процентах 0–100, тон), `links` — пары связанных участников, `steps` — шаги: подпись (`caption`), какие участники показаны (`show`), какие подсвечены (`focus`), потоки (`flows`: откуда, куда, тон), «Длительность» шага, «Показывать, только если» (`condition`) — шаг пропускается, пока условие ложно (например `user.percentUsed > 80`). Подписи участников и шагов — шаблоны, в них работают `{{ user.username }}`.

**Настройки инспектора:** «Запуск» (при загрузке, при появлении, по клику), «Повтор» (по кругу, один раз, туда и обратно), «Пауза при наведении», «Показывать номера шагов», «Скорость» (множитель 0,25–4), «Переход» (появление, сдвиг, масштаб), «Размер героев», «Форма героев» (круг, скруглённая, квадрат), «Линии» (сплошные, пунктир, анимированные), «Точки идут» (вперёд, назад, туда и обратно), «Скорость точек», «Точек на связь» (1–5), «Цвета тонов». Также: автозапуск, цикл, длительность шага по умолчанию, высота, показ подписи и панели управления; в редакторе — кнопка воспроизведения.

При `prefers-reduced-motion` сцена показывает последний шаг и не зацикливается.

Готовые сцены — в категории «Сцены» каталога (15 штук, см. ниже). Сцена `subpage` — анимированная справка по дизайнеру, открывается кнопкой «?» на верхней панели и один раз автоматически при первом открытии.

## Переменные и язык шаблонов

Вкладка **«Переменные»**: каталог всех путей с живыми значениями текущего клиента предпросмотра. Клик вставляет `{{ путь }}` в текстовое поле, в котором стоял курсор (сначала кликните в поле). Списки (`devices.items`, `links`, `mtProto`, `apps`) раскрываются: можно вставить готовый блок `#each` или поле элемента. Внизу — «Мои переменные» (собственные константы) и «Переводы».

### Синтаксис

```
{{ user.username }}                                  значение
{{ user.trafficUsed | upper }}                       фильтры цепочкой через |
{{ user.expiresAt | date("DD.MM.YYYY") }}            фильтр с аргументом
{{#if user.isActive}}вкл{{else if user.userStatus == "LIMITED"}}лимит{{else}}выкл{{/if}}
{{#each links as link}}{{ link.number }}. {{ link.title }}{{/each}}
{{ tr.welcome }}                                     текст на языке посетителя
{{ state.more }}                                     состояние страницы
```

Выражения: числа, строки в кавычках, `true` / `false` / `null`, пути (`a.b[0]`), операторы `! - * / % + < <= > >= == != && ||`, тернарный `?:`, вызовы функций. Работает в текстах, подписях кнопок, ссылках, URL картинок, QR, «Свой код» и в «Показывать, только если» (там без фигурных скобок). Ошибочный шаблон выводится как исходный текст, не ломая страницу. `#each` обрабатывает не более 200 элементов; внутри доступны `index` (с 0) и `number` (с 1); имя элемента задаётся через `as`, по умолчанию `item`.

### Основные пути

| Группа | Пути |
|---|---|
| Клиент | `user.username`, `user.userStatus` (ACTIVE, EXPIRED, LIMITED, DISABLED), `user.isActive`, `user.isOnline`, `user.group`, `user.shortUuid`, `user.createdAt`, `user.lastOnline`, `user.expiresAt`, `user.daysLeft` (9999 = бессрочно), `user.neverExpires` |
| Трафик | `user.trafficUsed`, `user.trafficLimit` (или ∞), `user.remaining`, `user.percentUsed` (0–100), `user.unlimited`, `user.trafficUsedBytes`, `user.trafficLimitBytes`, `user.lifetimeTrafficUsed` |
| Подписка | `subscription.url`, `.jsonUrl`, `.pageUrl`, `.happUrl`, `.v2raytunUrl` |
| Устройства | `devices.enabled`, `.max` (0 = без лимита), `.count`, `.left`, `.unlimited`, `.items[]` (`name`, `model`, `os`, `osVersion`, `firstSeenAt`, `lastSeenAt`, `active`, `number`) |
| Ссылки | `links[]` (`title`, `url`, `protocol`, `host`, `number`), `mtProto[]` (`title`, `url`, `number`) |
| Приложения | `apps[]` (`id`, `label`, `url`, `iconUrl`), `app.<id>.url` (например `app.happ.url`) |
| Страница | `branding.title`, `branding.supportUrl`, `page.lang`, `page.preview`, `page.device`, `page.url`, `now` |
| Свои | `vars.имя` («Мои переменные»), `tr.ключ` (переводы), `state.ключ`, `p.ключ` (параметры «Свой код») |

### Фильтры

`upper`, `lower`, `capitalize`, `trim`, `truncate(n)`, `default(x)`, `bytes`, `number(d)`, `percent(a, b)`, `date(fmt)`, `time`, `datetime`, `ago`, `plural(one, few, many)`, `join`, `first`, `last`, `len`, `replace`, `round`, `json`, `urlencode`, `b64`. Формат даты: `YYYY`, `YY`, `MMM`, `MM`, `DD`, `HH`, `mm`, `ss`; дата 9999 года выводится как `∞`. Функции в выражениях: `min`, `max`, `abs`, `floor`, `ceil`, `clamp`, `now`, `coalesce`, `contains`, `startsWith`, `endsWith` (и любой фильтр как функция).

### Мои переменные

«Добавить переменную» — имя и значение, например `tg` со ссылкой на бота; в макете `{{ vars.tg }}`. Хранятся в макете (`layout.vars`). Многие элементы каталога используют `vars.*` (`tg`, `notice`, `renewUrl`, `promo`, `promoEnds`, `referralUrl`, `ping`, `down`, `up`, `uptime`) и показываются, только если значение задано. При применении шаблона ваши переменные сохраняются и дополняются переменными шаблона.

## Переводы

**Как устроено.** Текст `{{ tr.ключ }}` разрешается в язык посетителя. Словарь собирается из трёх слоёв (позднее перекрывает раннее):

1. английские тексты **внутри макета** (`layout.i18n.en`);
2. **встроенный словарь** языка посетителя (только тексты готовых элементов каталога);
3. ваши тексты в макете для этого языка (`layout.i18n.<язык>`, при необходимости с регионом).

Если для языка перевода нет, подставляется английский. Если нет и английского — выводится пустая строка.

**Языки.** Всего 13: `en` и `ru` хранятся **внутри макета** у каждого готового элемента, ещё 11 подгружаются по требованию из встроенных словарей: `uk`, `es`, `tr`, `pt`, `id`, `vi`, `zh`, `tw` (китайский традиционный; для `zh-TW` и `zh-HK`), `ja`, `ar`, `fa`. Встроенные словари покрывают только тексты готовых элементов каталога и шаблонов; ваши собственные тексты для этих языков нужно перевести самим.

**Как редактировать.** Вкладка «Переменные» → «Переводы»:

- сверху чипы языков: `EN`, `RU` и языки из конфига (`locales`); «✓» — всё переведено, «−N» — не хватает N текстов, используемых в макете;
- «Поиск текстов…» (показываются первые 80, остальные — через поиск);
- клик по тексту раскрывает поля по каждому языку; в пустом поле подсказкой показан английский;
- «Добавить текст» — новый ключ (латиница, цифры, `_`);
- корзина «Удалить неиспользуемые тексты: N» чистит ключи, на которые нет ссылок `tr.…`.

Чтобы перевод встроенного словаря заменить своим, добавьте тот же ключ для нужного языка. Список показывает только тексты из макета, поэтому у языка, включённого только через встроенный словарь, поля редактирования появятся после добавления языка в конфиг (`locales`).

**Язык посетителя.** Определяется страницей подписки; переключатель языка (элемент «Выбор языка») виден при двух и более языках в конфиге. В редакторе язык предпросмотра выбирается на верхней панели. Тур «Перевести страницу» показывает этот путь на практике.

## Вкладка «Добавить»: базовые элементы и каталог

**Базовые элементы**: Фрейм, Текст, Кнопка, Картинка, Бейдж, Прогресс, Иконка, QR-код, Разделитель, Отступ, Повтор, Свой код, Шапка, Сцена, Кнопки приложений, Выбор языка. Клик добавляет элемент в выбранный фрейм или после выбранного элемента, перетаскивание кладёт в место отпускания.

**Каталог** — 108 готовых элементов:

- **Поиск** по названию, подсказке и тегам.
- **Категории** (чипы со счётчиком): «Моё хранилище», «Все», «Инструкции», «Сцены», «Анимации», «Профиль», «Трафик», «Устройства», «Подключение», «Инфо», «Декор», «Тарифы» (`plans`), «Соцсети» (`social`). - **Предпросмотр:** при наведении на карточку справа показывается живой предпросмотр на данных выбранного клиента и в палитре страницы.

Добавленный элемент дальше правится как обычные узлы; связи с каталогом нет. Готовые элементы содержат текст в виде `{{ tr.ключ }}`, поэтому переводятся через словарь.

## Вкладка «Стили»

Оформление всей страницы. Хранится в конфиге, а не в макете.

| Блок | Что делает | Поле конфига |
|---|---|---|
| «Палитра» | Сетка мини-превью 12 палитр | `colorPreset` |
| «Оформление» | «Авто» (следует за системной темой посетителя), «Светлая», «Тёмная» | `theme` (`system`, `light`, `dark`) |
| «Фон» | «Анимированный» (атмосфера палитры) или «Однотонный» | `branding.background` (`animated` / `plain`) |

## Хранилище («Моё хранилище»)

Хранилище — личная библиотека ваших элементов и целых страниц-шаблонов. В англоязычном интерфейсе называется «My library».

**Что можно сохранить.**

- **Элемент.** Выделите один или несколько элементов (с общим родителем) → закладка в инспекторе, ⌘/Ctrl+Shift+S или «Сохранить в хранилище…» в контекстном меню. В окне: «Название», «Описание», «Теги (через запятую)» и сводка «Что будет сохранено». Появится в «Добавить» → «Моё хранилище».
- **Шаблон страницы.** Кнопка-закладка на верхней панели («Сохранить страницу как шаблон»). Флажок «Сохранить палитру и фон» добавляет `colorPreset` и настройки фона и цветов. Шаблон появляется в галерее «Шаблоны», раздел «Мои шаблоны».

**Действия.** В меню «Ещё» карточки: «Переименовать / изменить описание», «Править на холсте» (только для элементов), «Обновить из выделения» / «Обновить из текущей страницы» (с подтверждением), «Дублировать» (название «… (копия)»), «Экспорт JSON», «Удалить». В шапке раздела: «Импорт» (файл `.json`; принимаются файл хранилища и одиночный элемент; совпавшие id заменяются новыми) и «Экспорт всего» (`sharx-library.json`).

**Где хранится.**

- **На сервере панели**, общий для **всех администраторов** и браузеров. Один JSON-документ (`{"version":1,"items":[…]}`) в настройке `designerLibrary`; не входит в общий ответ настроек. Эндпоинты (требуют входа в панель): `POST /panel/setting/designerLibrary/get` и `POST /panel/setting/designerLibrary/save` (тело `{"library": "<json-строка>"}`). Лимит на сервере — **8 МБ**; дизайнер предупреждает от 4,5 МБ и отказывается сохранять больше 6 МБ.
- **Автосинхронизация.** Изменения отправляются с задержкой около 0,7 с; в шапке видно состояние: «Сохранение…», «Сохранено в панели», «Локальная копия — повторить».
- **Офлайн-кэш.** Копия лежит в `localStorage` браузера. Если сервер недоступен, изменения сохраняются локально (статус «Локальная копия»), а при следующей синхронизации сливаются с серверной версией: побеждает более новая запись по каждому id.
- Удаление хранится как «надгробие» 30 дней, чтобы дойти до других браузеров.
- Защита от потери данных: пустую библиотеку поверх непустой дизайнер не запишет, нечитаемое серверное содержимое не перезатирает.
- Одновременное редактирование одного элемента двумя администраторами разрешается по времени изменения: побеждает более позднее.

## Что изменилось на странице настроек

Настройки → «Подписка» → «Публичная страница подписки (SharX)»:

- Вверху появилась карточка **«Визуальный конструктор»** с кнопкой «Открыть конструктор» и меткой «используется», когда макет включён.

- Вкладка **«Блоки»** скрыта, когда используется макет (макет включён или конфиг не менялся, то есть действует «Вау-шоукейс»): блоками теперь управляет дизайнер. ## Безопасность

- **Шаблонизатор без `eval`.** Выражения разбираются в дерево и вычисляются над обычными данными; `Function` и `eval` не используются. Обращения к `__proto__`, `constructor`, `prototype` запрещены.
- **Экранирование.** В HTML подставляемые значения экранируются. Ссылки со схемами `javascript:`, `data:`, `vbscript:`, `file:` блокируются в подставляемых значениях.
- **Санитайзер «Свой код» (без JS).** Разметка очищается разбором браузера: удаляются `script`, `iframe`, `frame`, `object`, `embed`, `link`, `meta`, `base`, `noscript` и др., все `on*`-атрибуты и `srcdoc`, небезопасные URL (`data:` допускается только для изображений). В CSS вырезаются `@import`, `expression(`, `javascript:`, `behavior:`, `-moz-binding`.
- **Скрипты.** Выполняются только в `iframe` с `sandbox` без `allow-same-origin`: у кода нет доступа к странице, cookie, сессии панели, `localStorage` страницы и родительскому документу. Данные передаются копией (`window.sub`).
- **Свои `@keyframes`** фильтруются (без `@`-правил, `url()` и разметки).
- **Публичный API** не отдаёт HWID устройств.
- Хранилище доступно только вошедшим администраторам панели.

## Ограничения и известные особенности

- **Нет мобильной адаптации редактора.** Интерфейс дизайнера предназначен только для компьютера: он занимает весь экран, имеет две фиксированные боковые панели (300 и 320 px) и рассчитан на мышь (перетаскивание, правый клик, Shift/Alt/сочетания клавиш, наведение для предпросмотра). На телефоне и планшете редактировать нельзя. Готовая страница подписки, напротив, адаптивная: её можно смотреть в рамке «Телефон» и настраивать отдельный мобильный вид (порог 640 px).
- Тексты готовых элементов лежат внутри макета на английском и русском; ещё 11 языков подгружаются из встроенных словарей и покрывают только готовые элементы. Собственные тексты нужно переводить самим. Без перевода показывается английский.
- Встроенные анимации уважают `prefers-reduced-motion`; у посетителей с этой настройкой они не проигрываются.
- «Свой код» с JavaScript работает в `iframe` без доступа к странице: скрипт не может менять окружающий макет, читать его DOM или вызывать функции страницы; связь только через `window.sub`. Высота iframe: авто (20–4000 px) или фиксированная.
- «Свой код» без скриптов не выполняет JavaScript вообще; `<script>` вырезается.
- Правка CSS страницы действует только внутри страницы (ограничивайте селектором `.sublyt`); переменные `{{ }}` там не подставляются.
- `state.<ключ>` живёт только в открытой странице и сбрасывается при перезагрузке.
- Режим анимации «По прокрутке» использует `animation-timeline`; в браузерах без поддержки работает как «При появлении».
- `#each` обрабатывает первые 200 элементов списка.
- Избранное, «Недавние», вид каталога, настройки сетки и состояние тура хранятся в `localStorage` браузера и не синхронизируются между администраторами. Хранилище синхронизируется через сервер.
- Лимит хранилища 8 МБ на сервере (6 МБ на записи из дизайнера). Крупные картинки в `data:`-URL быстро исчерпывают его; используйте ссылки.
- Категории «Тарифы» и «Соцсети» пока без перевода названий (показываются как «Plans» и «Social»); часть названий полей в «Свои цвета» также выводится по-английски.
- Готовые элементы с `vars.*` требуют заполнить переменные, иначе скрыты или показывают пустое значение.
- Правки макета до нажатия «Сохранить» видны только вам в дизайнере.

## Частые вопросы и решение проблем

**Клиенты не видят мой дизайн.** Проверьте флажок «Показывать на странице» (`layout.enabled`) и нажмите «Сохранить». Проверьте страницу вручную: `/panel/sub/?id=<subId>` тестового клиента. Браузер может держать кэш: обновите жёстко.

**Я включил макет, а вкладки «Блоки» больше нет.** Так и задумано: пока действует макет, блоки настраиваются в дизайнере. Чтобы вернуться к блокам, выключите «Показывать на странице» и сохраните; вкладка «Блоки» вернётся.

**Не видно вкладку «Блоки» на свежей установке.** Если конфиг не менялся, страница показывает шоукейс-макет по умолчанию, а вкладка «Блоки» скрыта. Откройте дизайнер, выключите «Показывать на странице» и сохраните: вкладка «Блоки» и классическая страница вернутся.

**Нельзя редактировать с телефона.** Так и есть: дизайнер только для компьютера. Откройте панель на компьютере. Готовую страницу проверьте в рамке «Телефон» или реально на телефоне по ссылке подписки.

**Переменная выводится как `{{ … }}` или пусто.** Проверьте путь (клик по нему во вкладке «Переменные» вставит правильный), закрытость `{{#if}}` / `{{#each}}`, запятые между аргументами фильтров. Ошибочный шаблон выводится как исходный текст. Пустое значение: для `vars.*` не задана переменная, для `devices.*` у клиента выключен лимит устройств.

**Элемент пропал.** Проверьте «Показывать, только если» (индикатор «Сейчас: скрыт»), «Скрыть на мобильных» / «Скрыть на десктопе», глаз в «Слоях» и действие «Показать / скрыть элемент» у кнопок. Может быть включена «Невидимый (место сохраняется)».

**Ряд не встал.** Перетаскивайте на левый или правый край элемента внутри **стека** (не «свободного» фрейма). Или выделите элементы Shift+кликом и «Расположить рядом».

**Свободный фрейм схлопнулся.** Задайте ему фиксированную высоту.

**Анимация не играет.** Проверьте «Запуск» (для «По клику» нужен клик, «При появлении» — прокрутка до элемента), не включено ли у вас в системе «уменьшение анимации» и что выбран эффект, отличный от «Нет». В редакторе анимация ставится на паузу под курсором.

**Не работает мой скрипт.** Включите «Разрешить JavaScript»; скрипт запускается в песочнице и не видит страницу, данные берите из `window.sub`. Открыть в новой вкладке ссылки можно (`allow-popups`).

**Хранилище показывает «Локальная копия — повторить».** Сервер недоступен или ответил ошибкой; изменения сохранены в браузере. Нажмите на статус для повтора. Если размер приближается к 6 МБ, удалите лишнее или экспортируйте и очистите.

**Мои элементы хранилища не видны на другом компьютере.** Хранилище общее для сервера, но синхронизация идёт при открытии дизайнера. Откройте дизайнер заново; если на этом компьютере статус «Локальная копия», проверьте доступность панели.

**Тур не запускается.** «Тур» → «Сбросить подсказки», либо выберите дорожку вручную. Состояние тура хранится в браузере и не работает в приватном окне без хранилища.

**Как вернуть классическую страницу.** Выключите «Показывать на странице» и сохраните: блоки заработают снова. Макет сохранится на случай возврата.

**Как откатить неудачную правку.** ⌘/Ctrl+Z. История действует, пока дизайнер открыт; после «Сохранить» и закрытия отмена уже невозможна.

## Горячие клавиши

⌘ на macOS, Ctrl на остальных системах. Клавиши не действуют, пока фокус в поле ввода или редакторе кода.

| Сочетание | Действие |
|---|---|
| ⌘/Ctrl+Z | Отменить |
| ⇧⌘/Ctrl+Shift+Z или ⌘/Ctrl+Y | Повторить |
| ⌘/Ctrl+D | Дублировать |
| ⌘/Ctrl+C / ⌘/Ctrl+V | Копировать / вставить внутрь |
| ⌘/Ctrl+G | Сгруппировать во фрейм |
| ⇧⌘/Ctrl+Shift+G | Разгруппировать |
| ⇧⌘/Ctrl+Shift+R | «Расположить рядом» / «Разбить строку» |
| ⇧⌘/Ctrl+Shift+S | Сохранить выделенное в хранилище |
| ⌘/Ctrl+S | Сохранить страницу |
| Delete / Backspace | Удалить |
| G | Показать / скрыть сетку |
| Стрелки, Shift+стрелки | Сдвиг в свободном фрейме на шаг / на 10 шагов |
| Alt при перетаскивании | Временно отключить привязку |
| Shift+клик | Добавить в выделение |
| Двойной клик по тексту | Правка на месте |
| Esc | Снять выделение; повторно — закрыть дизайнер |
