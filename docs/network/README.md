# SharX Network beta

**Доступ к сети пока предоставляется по запросу оператору проекта.** Для подключения панели требуется приглашение. Установка beta не предоставляет участие автоматически.

В этой репе находятся клиент панели, публичный wire-протокол, денежные единицы контракта, код worker-ноды и проверочные primitives свидетеля.

- [Контракт API](api.md)
- [Тариф и семидневное удержание](ADR-0002-credit-economy.md)
- [Границы защиты](threat-model.md)

Сервер координатора, расчётный реестр, SQL-миграции, операторская панель, развёртывание и интеграционный стенд вынесены в отдельный приватный репозиторий. Их не следует копировать в публичную репу. Конечный пользователь подключается напрямую к exit-ноде; relay через оператора не используется.

Закрытая beta не означает доказательства каждого байта трафика. Допуск платных сессий требует настройки независимых свидетелей. Программный валидатор перед ядром ещё не реализован и сам по себе не защищает от root владельца хоста.
